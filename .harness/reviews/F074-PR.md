# Pull Request: F074 — Repository discovery

## Description
Implements organization and group-wide repository discovery, filtering, and scan scoping for DiagramHQ. Enables engineering and architecture teams to enumerate repositories across GitHub organizations or GitLab groups/namespaces, filter by technology or search criteria, inspect repository metadata, and multi-select an active subset of repositories to scope architecture modeling scans.

Strict Acceptance Invariant:
- Discovery lists repositories with rich metadata (languages, frameworks, stars, activity).
- Selection strictly scopes downstream scan operations, guaranteeing unselected repositories are excluded.

### Key Additions
1. **Domain Layer (`packages/domain/src/repository-discovery.ts`)**:
   - `DiscoveredRepository`, `RepoProvider`, `DiscoveryFilter`, `RepoDiscoverySession`, `ScopedDiscoverySummary`.
   - `filterRepositories`: filters repositories by text query, primary language, and frameworks, while handling archived status.
   - `scopeScanTargets`: enforces the core invariant by strictly filtering repositories to selected IDs.
   - `summarizeDiscoveryScope`: computes scoped summary metrics (total selected, language distribution, estimated service count).
   - `createDiscoverySession`: initializes an interactive discovery session with active repositories preselected.
   - `packages/domain/src/repository-discovery.test.ts`: 5 unit tests verifying repository listing, query and language filtering, strict selection scoping, summary statistics, and empty selections.
   - `packages/domain/src/index.ts`: Exported `repository-discovery`.

2. **Web Layer (`apps/web/components/canvas/repo-discovery-panel.tsx`)**:
   - `<RepoDiscoveryModal />`: interactive discovery modal with provider switcher (GitHub 🐙 / GitLab 🦊), organization input, text search, language filters, Select All/Clear controls, repository cards with metadata badges, and a scoped summary footer.
   - `apps/web/components/canvas/index.ts`: Exported repository discovery components.
   - `apps/web/repo-discovery.spec.tsx`: 4 integration tests verifying modal rendering, filter interactions, strict selection scoping, and modal dismiss states.
