# Pull Request: F127 — SDK

## Description
Typed TypeScript client SDK over the DiagramHQ REST and architectural model APIs. Enables developer automation, external microservice integrations, CLI tooling, and programmatic architecture management:
- Strongly typed TypeScript client SDK (`DiagramHQClient`, `createDiagramHQClient`) supporting:
  - Architectures: CRUD, model snapshots (`getModel`), versions
  - Model Objects: CRUD (person, system, container, component, store, actor)
  - Connections: CRUD (protocols, ports, labels, sync/async kinds)
  - Views: CRUD (C4 level 1-4 views, projections)
  - Flows: CRUD (step sequences, interactive transaction simulations)
- Robust Error Hierarchy: `DiagramHQApiError`, `AuthenticationError` (401), `NotFoundError` (404).
- Extensible HTTP Transport: supports standard `fetch`, custom HTTP adapters, and in-memory test servers (`createMockTestServer`).
- Verified CRUD round-trip: verified full create, read, update, delete cycle against a local mock test server.

### Key Additions
1. **Domain Layer (`packages/domain/src/sdk.ts`)**:
   - Interfaces: `SdkConfig`, `SdkHttpTransport`, `SdkHttpResponse`, `TestServerState`, `CreateModelObjectInput`, `UpdateModelObjectInput`, `CreateModelConnectionInput`, `CreateViewInput`, `CreateFlowInput`.
   - Classes: `DiagramHQClient`, `DiagramHQApiError`, `AuthenticationError`, `NotFoundError`.
   - Factory functions: `createDiagramHQClient`, `createMockTestServer`.
   - `packages/domain/src/sdk.test.ts`: 5 unit tests verifying configuration, auth headers, error propagation (401, 404, 500), and full end-to-end CRUD round-trip against the test server.
   - `packages/domain/src/index.ts`: Exported SDK module.

2. **Web Layer (`apps/web/components/canvas/sdk-panel.tsx`)**:
   - `<SdkPanelModal />`: Developer modal featuring code snippet generators for TypeScript SDK, cURL, and CLI (`dhq`), API key/base URL configuration, resource switcher (architectures, objects, connections, views, flows), copy-to-clipboard, and an interactive in-memory SDK round-trip test playground.
   - `apps/web/components/canvas/index.ts`: Exported SDK panel.
   - `apps/web/sdk.spec.tsx`: 3 integration tests verifying modal rendering, closed state, and snippet generation.
