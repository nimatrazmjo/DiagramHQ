# F044 — Flow playback

## Description
This PR implements F044 — Flow playback (Phase 05 — Flows).

Provides interactive step-by-step playback through sequence flows:
- Interactive step-by-step playback through sequence flows.
- Pure domain state machine in `packages/domain/src/flow-playback.ts` managing playback state (`idle`, `playing`, `paused`, `completed`), speed control (`0.5x`, `1x`, `2x`, `4x`), loop toggling, next/prev navigation, seek, and interval timing.
- Canvas toolbar UI component `<FlowPlaybackToolbar />` with Play, Pause, Next, Prev, Restart, Step counter, Speed selector, and Loop toggle.
- Full verification across domain unit tests and web integration tests.

### Changes

**Domain layer (`packages/domain/src/`)**
- Added `flow-playback.ts`:
  - `createFlowPlayback(flow, options?)` — initializes playback state machine.
  - `playFlow(state)` — advances to `playing`.
  - `pauseFlow(state)` — transitions to `paused`.
  - `nextFlowStep(state)` — advances active step index, handles loop and completion.
  - `prevFlowStep(state)` — decrements active step index, clamping at 0.
  - `restartFlow(state)` — resets active step to 0 and state to `playing`.
  - `setFlowSpeed(state, speed)` — sets speed multiplier (`0.5x` to `4x`).
  - `seekFlowStep(state, stepIndex)` — clamps target step within sequence range.
  - `computeStepIntervalMs(state, baseIntervalMs?)` — calculates timer interval taking playback speed into account.
- Added 8 unit tests in `packages/domain/src/flow-playback.test.ts`.
- Exported flow playback types and functions from `packages/domain/src/index.ts`.

**Web layer (`apps/web/`)**
- Added `apps/web/components/canvas/flow-playback-toolbar.tsx` (`FlowPlaybackToolbar` component).
- Exported `FlowPlaybackToolbar` from `apps/web/components/canvas/index.ts`.
- Added integration test suite in `apps/web/flow-playback.spec.ts` (4 tests).
