## Description
Implements **F018 — Architecture model** from Phase 03 (Architecture Model): the model-first core where objects and connections are persisted independently of any diagram or view (DEC-001 / ADR-0001).

- **Domain Layer (`packages/domain`)**:
  - `ArchitectureModel` snapshot interface capturing `{ architecture, version, objects, connections }`.
  - Immutable domain manipulation functions: `createArchitectureModel`, `addModelObject`, `updateModelObject`, `removeModelObject` (with cascade connection removal per Invariant 4), `addModelConnection`, `updateModelConnection`, `removeModelConnection`.
  - Invariant validation (`validateArchitectureModel`): validates endpoint existence, single-architecture/version boundaries, no self-connections (`canConnect`), and no cyclic parent hierarchies (`hasParentCycle`).
  - Model identity verification: `isModelIdentical(a, b)` verifying deep equality regardless of array ordering.
- **API Layer (`apps/api`)**:
  - New `ArchitecturesModule` with controller, service, and DTOs.
  - Endpoints conforming to `API_SURFACE.md`:
    - `POST /workspaces/:workspaceId/architectures`: creates architecture + default 'main' version.
    - `GET /architectures/:id`, `PATCH /architectures/:id`, `DELETE /architectures/:id`.
    - `GET /architectures/:id/model`: loads full snapshot `{ architecture, version, objects, connections }`.
    - `GET /architectures/:id/objects`, `POST /architectures/:id/objects`, `GET /objects/:id`, `PATCH /objects/:id`, `DELETE /objects/:id` (cascades connections).
    - `GET /architectures/:id/connections`, `POST /architectures/:id/connections`, `GET /connections/:id`, `PATCH /connections/:id`, `DELETE /connections/:id`.
  - RBAC & multi-tenant isolation enforced via workspace membership and `canWrite(role)`.
  - 18 comprehensive E2E tests in `apps/api/src/architectures/architectures.e2e.spec.ts`.
- **Web Client Layer (`apps/web`)**:
  - `ArchitectureModelClient` in `apps/web/lib/model/architecture-model-client.ts`.
  - Manages client-side model state independent of diagrams and Zustand (Layer Boundary Rule 4).
  - Optimistic updates with guaranteed rollback on API error.
  - Subscriptions for reactive UI synchronization.
  - Canvas projection bridge (`toCanvasProjection`) projecting domain objects and connections to canvas nodes and edges.
  - 8 unit tests in `apps/web/architecture-model.spec.ts` verifying model isolation, reload identity, and optimistic rollback.
