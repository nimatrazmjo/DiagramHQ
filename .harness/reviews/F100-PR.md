# F100 — SVG — Pull Request

## Summary
Implements high-fidelity SVG architecture diagram export matching the interactive canvas styling for DiagramHQ (Phase 12 — Documentation). Delivers pure TypeScript SVG vector compilation producing standalone, W3C-compliant SVG documents with custom C4 shape silhouettes and inline kind icons, technology and governance pills, parent system and boundary enclosures with dashed borders, multi-style edge routing (curved Bezier, orthogonal, straight) with centered protocol chips, background dot grid patterns, theme palettes (Dark Canvas, Light Paper, Transparent Vector), interactive hover `<title>` tooltips, and an interactive canvas modal with viewport zoom/pan, settings sidebar, SVG markup viewer, copy, and download actions.

## Changes

### Domain (`packages/domain/src/`)
- **`svg-export.ts`**: Pure vector SVG export engine:
  - **Theming & Color Palettes (`SVG_THEME_PALETTES`)**:
    - `dark`: DiagramHQ dark canvas `#090D16`, `#1E293B` dot grid, C4 element color cards.
    - `light`: Clean paper background `#F8FAFC`, high contrast border and label colors.
    - `transparent`: Clean vector embed with transparent canvas background for presentation decks.
  - **Inline Iconography & Typography (`getNodeKindIconPath`, `escapeSvgText`)**:
    - Distinctive SVG path geometry for each C4 kind: `actor` (user silhouette), `store` (database cylinder), `application` (browser window), `component` (modular puzzle), `system` (cloud server).
    - Embedded typography (`Inter, system-ui, -apple-system, sans-serif`) and monospace badges.
    - Robust XML/SVG text escaping for special characters (`&`, `<`, `>`, `"`, `'`).
  - **Edge Routing Engine (`calculateSvgEdgePath`)**:
    - `curved`: Smooth cubic Bezier curves (`M x1 y1 C cx1 cy1, cx2 cy2, x2 y2`) matching the canvas edge router.
    - `orthogonal`: Right-angle stepped paths (`M x1 y1 L midX y1 L midX y2 L x2 y2`).
    - `straight`: Direct point-to-point lines (`M x1 y1 L x2 y2`).
  - **High-Fidelity Renderer (`renderViewToFidelitySvg`)**:
    - Resolves coordinates using explicit `viewObjects` positions or deterministic auto-grid layout.
    - Computes tight responsive bounding boxes (`viewBox`) with custom padding and scale multipliers.
    - Generates parent system and group enclosing boundary cards (`<rect stroke-dasharray="6,4" ...>`) with header banner labels.
    - Generates relationship edges with centered protocol/label pills, distinct markers (`#arrow-sync`, `#arrow-async`), and dashed strokes for asynchronous events.
    - Generates node cards with header accent bars, kind icons, kind badges, active health dot indicators, title, description, and technology/owner pills.
    - Supports interactive `<title>` hover inspection tags on nodes and connections.
    - Generates C4 component kind legend and background dot grid patterns.
    - Computes base64 data URI, FNV-1a checksum, and sanitized filename.
- **`svg-export.test.ts`**: 10 unit tests covering edge routing calculations, node kind icon paths, XML escaping, full SVG document generation, orthogonal routing, light/transparent themes, display toggles, and resolution scaling.
- **`index.ts`**: Exported `svg-export`.

### Web (`apps/web/`)
- **`components/canvas/svg-export-modal.tsx`**: `<SvgExportModal />` canvas UI:
  - 3 Navigation Tabs: `Interactive Preview`, `Fidelity & Styling Options`, `SVG XML Markup`.
  - Interactive Preview Tab:
    - Live SVG canvas container rendering the compiled SVG graphic.
    - Viewport zoom controls (Zoom In, Zoom Out, Reset 100%) and ViewBox coordinate indicator.
  - Fidelity & Styling Options Tab:
    - Visual theme palette switcher: Dark Canvas, Light Paper, Transparent Vector.
    - Edge routing switcher: Curved (Bezier), Orthogonal, Straight.
    - Resolution scale selector: 1x, 2x, 3x with live pixel dimensions readout.
    - Display toggles: Dot Grid Pattern, Technology & Owner Badges, Header & Scope Banner, Component Kind Legend, Interactive SVG Tooltips.
    - Custom diagram title override input.
  - SVG XML Markup Tab:
    - Formatted XML source viewer with character count and verification badge.
  - Modal Footer:
    - Quick metrics badges: Element count, Connection count, File size.
    - Filename and pixel dimensions indicator.
    - "Copy Data URI", "Copy SVG Markup", and "Download SVG File" action buttons.
- **`components/canvas/index.ts`**: Exported `svg-export-modal`.
- **`svg-export.spec.tsx`**: 3 integration tests verifying modal closed state, open modal layout with tabs and action buttons, and live SVG graphic rendering with canvas elements and connections.
