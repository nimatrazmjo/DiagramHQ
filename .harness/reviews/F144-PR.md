# Pull Request: F144 — Wire the editor to the model API

## Summary of Changes

### Architectural Shift: From Diagram Blobs to First-Class Model Persistence
Previously, DiagramHQ Studio persisted canvas contents as an opaque JSON blob inside workspace settings (`workspace.settings.studioDiagram`), completely disconnected from the rich domain model endpoints in `@diagramhq/api` (`/architectures/:id/objects`, `/connections`, `/views/:viewId/objects/positions`).

With F144, the editor is fully wired to the live architecture model API:
1. **Model Proxy Catch-All Routes**:
   - Added Next.js route handlers `apps/web/app/architectures/[...slug]/route.ts`, `apps/web/app/objects/[...slug]/route.ts`, `apps/web/app/connections/[...slug]/route.ts`, and `apps/web/app/views/[...slug]/route.ts` with transparent authentication forwarding (`signApiToken`, `fetchFromApi`) and graceful in-memory fallback store (`inMemModelStore`) for tests and guest/offline modes.
2. **Architecture Model Client Enhancements**:
   - Extended `apps/web/lib/model/architecture-model-client.ts` with bidirectional mapping between canvas nodes/edges and domain model objects/connections (`mapCanvasKindToModelKind`, `mapModelKindToCanvasKind`, `mapCanvasNodeToModelObject`, `mapCanvasEdgeToModelConnection`, `mapModelObjectToCanvasNode`, `mapModelConnectionToCanvasEdge`).
   - Added `loadFromModel(model, viewObjects)` projection creating canvas nodes with their per-view coordinates and edges from model connections.
3. **Autosave & Reopening Overhaul**:
   - Updated `apps/web/app/api/diagrams/autosave/route.ts`:
     - Resolves or automatically initializes an `Architecture` and default `View` for the workspace.
     - Automatically migrates legacy `settings.studioDiagram` blobs into genuine model objects, connections, and view object positions, and strips the legacy blob from settings.
     - GET loads nodes and edges directly from `/architectures/:id/model` and `/views/:viewId/objects`.
     - POST persists objects and connections to `/architectures/:id/objects` and `/connections`, and batch-persists layout coordinates to `/views/:viewId/objects/positions`.
4. **Studio Page Real-Time Persistence**:
   - Wired `architectureId`, `viewId`, and real-time model persistence callbacks (`persistModelObject`, `deleteModelObject`, `persistModelConnection`, `deleteModelConnection`, `handleBatchPersist`, `handleSinglePersist`) to `InfiniteCanvas` node and edge lifecycle handlers (`onNodeCreate`, `onEdgeConnect`, `onEdgeReconnect`, `onNodeRename`, `onNodeMetadataUpdate`, `onEdgeDisconnect`, `onEdgeLabelChange`).
5. **Testing**:
   - Added `apps/web/editor-model-wiring.spec.tsx` with 9 automated tests verifying bidirectional mapping, model proxy endpoints, autosave migration, batch position updates, and model-to-canvas projection.
