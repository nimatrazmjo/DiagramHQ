# Pull Request: F120 — AI evidence + confidence

## Description
Implements the AI grounding and confidence scoring engine for DiagramHQ. Fulfills the foundational invariant that every AI assertion, generated dependency, architectural edit, or synthesized claim must be anchored to concrete source evidence (repo, file path, line numbers, symbols, commit SHA, configuration rules) accompanied by a mathematically calibrated confidence score (0.00 to 1.00).

### Key Additions
1. **Domain Layer (`packages/domain/src/ai-confidence.ts`)**:
   - `AIEvidence` model: tracks `sourceType` (`ast_call`, `network_trace`, `config_file`, `import_statement`, `git_history`, `doc_comment`, `heuristic`, `manual`), structured `CodeLocation` (`repo`, `filePath`, `lineStart`, `lineEnd`, `symbol`, `commitSha`, `snippet`), human-readable formatted citations (e.g. `github.com/acme/orders:src/services/checkout.ts#L42-L55`), and evidentiary strength ratings.
   - `evaluateConfidence`: calculates calibrated confidence assessments with corroboration bonuses, penalties for missing file paths/line numbers, and automatic low-confidence detection below the 0.60 threshold.
   - `generateGroundedDependency`: synthesizes architecture dependencies (`ModelConnection`) carrying verified evidence citations and confidence metrics.
   - Low confidence flags: automatically marks `isLowConfidence: true`, `flagged: true`, and `requiresHumanVerification: true` with actionable explanatory reasons when claims are weak or unanchored.
   - `attachEvidenceToEdit` & `createGroundedAssertion`: wraps natural-language edits and architectural claims with full grounding trace.
2. **Web Layer (`apps/web/components/canvas/ai-confidence-badge.tsx`)**:
   - `<ConfidenceBadge />`: reactive pill showing confidence tiers (`HIGH`, `MEDIUM`, `Flagged Low Confidence`) with score percentages and status colors.
   - `<AIEvidenceCard />`: itemized evidence viewer displaying evidence source type, strength gauge, code snippet, and formatted citation.
   - `<AIEvidenceInspector />`: interactive inspector modal supporting filtering across all claims, high-confidence verifications, and flagged low-confidence alerts requiring human sign-off.
3. **Tests**:
   - 6 domain unit tests in `packages/domain/src/ai-confidence.test.ts`.
   - 4 web integration tests in `apps/web/ai-confidence.spec.tsx`.

## Acceptance Criteria

- [x] Test: a generated dependency includes evidence; low confidence flagged.
