# Pull Request: F080 — GCP

## Description
Google Cloud Platform (GCP) cloud infrastructure import and topology mapping engine for DiagramHQ (Phase 10 — Infrastructure Integrations). Provides complete feature parity with F078 (AWS) and F079 (Azure), enabling engineering teams to import and map real GCP cloud architectures across organizations, projects, and regions directly into the DiagramHQ architecture model:
- Discovers and maps all 17 canonical GCP resource types:
  - Compute & Serverless: `compute_instance` (GCE VMs), `gke_cluster` (Kubernetes Engine), `cloud_run_service` (Containerized microservices), `cloud_function` (Serverless compute), `app_engine` (PaaS apps)
  - Databases: `cloud_sql` (Managed relational MySQL/PostgreSQL/SQL Server), `spanner_instance` (Globally distributed ACID database), `bigtable_instance` (NoSQL analytical/operational), `firestore_database` (Document NoSQL)
  - Storage: `storage_bucket` (Google Cloud Storage)
  - Networking & Ingress: `vpc_network` (Virtual Private Cloud), `load_balancer` (Cloud HTTPS/TCP Load Balancer), `cloud_cdn` (Global CDN cache), `api_gateway` (Serverless API Gateway)
  - Messaging & Async: `pubsub_topic` (Enterprise messaging broker), `pubsub_subscription` (Pull/push subscriber), `eventarc_trigger` (Event-driven trigger), `cloud_tasks_queue` (Asynchronous task execution queue)
- Maps GCP resources into typed `ModelObject` records with:
  - `kind`: `'group'` for VPC networks, `'store'` for databases & storage buckets, `'application'` for compute, ingress, & load balancers, `'component'` for messaging brokers, queues, & triggers
  - Standardized metadata: GCP Resource URIs (`//compute.googleapis.com/...`), project ID, organization ID, region, zone, network name, subnetwork name, and labels
  - Hierarchical containment: resources located inside a VPC network have `parentId` anchored to the VPC group object when VPC containment is enabled
- Inter-resource connection inference:
  - Detects and creates typed `ModelConnection` records between interdependent GCP services:
    - Cloud CDN -> Load Balancer (Origin cache acceleration)
    - Load Balancer -> Cloud Run / GCE / GKE (Traffic routing & HTTP/HTTPS ingress)
    - API Gateway -> Cloud Functions / Cloud Run (Managed backend API invocation)
    - Cloud Run / Cloud Functions / GCE / GKE -> Cloud SQL (Relational database queries), Cloud Spanner (High-throughput gRPC transactions), Bigtable, Firestore, and GCS buckets
    - Cloud Run / Cloud Functions -> Pub/Sub (Asynchronous message publication)
    - Pub/Sub -> Cloud Functions / Cloud Run (Subscription push delivery)
    - Eventarc -> Cloud Functions / Cloud Run (Event-driven cloud routing)
    - Cloud Tasks -> Cloud Run / Cloud Functions (Asynchronous queued dispatch)
- Traceable cloud evidence: generates `GcpCloudEvidence` records (`sourceType: 'cloud_resource'`) with 100% confidence referencing raw GCP Resource URIs, project ID, organization ID, and regions.
- Acceptance test verified: imported a mocked GCP project with all 17 canonical GCP resource types correctly mapped to model objects, connections, and evidence.
