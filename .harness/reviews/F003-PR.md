## Summary of Changes

Implements **F003 — Organizations** from Phase 01 (Foundation):
- **Domain Layer (`packages/domain`)**:
  - Registered `mem` prefix in `IdPrefix` and exported `MemberId`.
  - Updated `Member` interface to use `MemberId`.
- **API Layer (`apps/api`)**:
  - Implemented `OrganizationsModule`, `OrganizationsService`, and `OrganizationsController`.
  - Added endpoints:
    - `POST /organizations`: Creates an organization and transactionally assigns caller as `owner` member. Supports custom or auto-slugified slug.
    - `GET /organizations`: Lists organizations where caller is an active member with their assigned role.
    - `GET /organizations/:id`: Retrieves organization details (scoped strictly to membership; returns 404 for unassociated callers).
    - `PATCH /organizations/:id`: Updates name and slug (guarded to `owner` and `admin` roles).
    - `DELETE /organizations/:id`: Deletes organization (guarded strictly to `owner` role).
    - `GET /organizations/:id/members`: Lists members of the organization.
  - Implemented input validation with `CreateOrganizationDto` and `UpdateOrganizationDto`.
  - Added unit test suite in `organizations.service.spec.ts` (15 tests).
  - Added e2e integration test suite in `organizations.e2e.spec.ts` (9 tests) verifying end-to-end CRUD and cross-tenant isolation.
- **Web Layer (`apps/web`)**:
  - Added `lib/api-token.ts` for signing stateless JWT tokens from user sessions for backend calls.
  - Added server actions in `app/dashboard/actions.ts` to create and list user organizations.
  - Implemented `CreateOrgForm` client component with validation and user feedback.
  - Updated `/dashboard` page to display the user's organizations and creation form.
  - Added unit test in `auth.spec.ts` verifying token signing.
