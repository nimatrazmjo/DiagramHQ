# PR: F038 — Security views

Branch: `feat/F038-security-views` -> `main`

## Summary
Implements Phase 04 feature F038 (Security views) by allowing trust boundaries and security attributes to be visually projected as overlays on canvas diagrams.

## Changes
- Updated UI node components (`system-node`, `app-node`, `database-node`, `component-node`) to optionally render security badges via a generic `SecurityBadges` component.
- Implemented `projectSecurityViewToCanvas` to inject security data properties into nodes and automatically enclose objects within `GroupNode` trust boundaries based on `metadata.trustZone`.
- Updated test specifications to ensure `projectSecurityViewToCanvas` handles nested scopes, public endpoints, auth, and compliances properly.
