# Pull Request: F126 — Webhooks

## Description
Outbound webhook delivery and lifecycle event notification engine for DiagramHQ. Enables external systems, CI/CD pipelines, audit monitors, and collaboration tools to subscribe to real-time architectural lifecycle events:
- Emits standard lifecycle events:
  - `object.*` (`object.created`, `object.updated`, `object.deleted`)
  - `connection.*` (`connection.created`, `connection.updated`, `connection.deleted`)
  - `diagram.created`
  - `flow.created`
  - `architecture.updated`
  - `version.created`
  - `change.approved`
  - `change.merged`
- Cryptographic security: calculates standard HMAC SHA-256 signatures (`X-Hub-Signature-256`) using per-subscription secret tokens (`whsec_...`).
- Multi-subscription registry: supports exact event filtering, category wildcards (`object.*`, `connection.*`), global wildcard (`*`), and architecture scoping.
- Delivery pipeline: records delivery logs with HTTP status code, round-trip latency (ms), HMAC signature, and error diagnostics.
- Test Sink verification: verified end-to-end dispatch of architectural events to a test sink endpoint.
