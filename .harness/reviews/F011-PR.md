# PR: F011 — Object Selection

## Summary
- Implements single-click node and edge selection on the canvas with synchronized UI state in `useCanvasStore`.
- Adds active visual styling rings to `SystemNode`, `AppNode`, and `StoreNode` when selected.
- Implements Escape key listener and background pane click handler to clear selection.
- Displays selection count indicator badge (`data-testid="selection-badge"`) and toolbar `Clear` button whenever items are selected.
- Enhances `useCanvasStore` with `selectNode`, `selectEdge`, `isNodeSelected`, `isEdgeSelected`, and `clearSelection` without domain entity storage (Layer Boundaries Rule 4).
- Adds 10 automated unit and component tests in `apps/web/selection.spec.ts` for a monorepo total of 245 passing tests.
