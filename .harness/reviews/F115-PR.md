# F115 — Persona modes

## Description
This PR implements F115 — Persona modes, satisfying the "Same model, different lens" feature of Phase 04.

Modes: architect, developer, security, SRE, data, product, executive, auditor. A persona re-scopes the render without changing the model.

### Changes
- Added `packages/domain/src/persona-view.ts` — `projectPersonaViewToCanvas()` projection that wraps the base canvas projection and stamps `personaMode` + `personaView: true` onto all node and edge data.
- Added `packages/domain/src/persona-view.test.ts` — unit test verifying that `personaMode` and `personaView` are correctly set on nodes when using the `security` persona.
- Added `apps/web/components/canvas/persona-badges.tsx` — `<PersonaBadges />` component that renders a persona-mode indicator badge (distinct icon + colour per persona) on canvas nodes when `personaView` is active.
- Integrated `<PersonaBadges />` into `app-node.tsx`, `system-node.tsx` (both external and internal sections), `database-node.tsx`, and `component-node.tsx`.
- Exported `projectPersonaViewToCanvas` and `PersonaMode` from `packages/domain/src/index.ts` (already present from prior domain scaffolding).
- Added `apps/web/persona-modes.spec.ts` — 3 integration tests:
  1. All 8 personas produce `personaView=true` and correct `personaMode` on nodes+edges.
  2. Switching persona re-scopes the render without mutating the underlying model.
  3. Default persona (no mode specified) is `architect`.

## Acceptance Criteria Coverage
- ✅ Modes: architect, developer, security, SRE, data, product, executive, auditor — all 8 implemented in `PersonaMode` type + `PERSONA_CONFIG` map.
- ✅ A persona re-scopes the render without changing the model — projection creates new node/edge objects; original model objects are never mutated.
