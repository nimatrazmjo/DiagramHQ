## Description
Implements **F025 — Component** from Phase 03 (Architecture Model): Component element CRUD, rendering, parent application linkage (`parentId`), component kinds (Controller, Service, Repository, Middleware, Handler, Utility), technology tagging, interfaces listing, code reference linking, and canvas projection.

- **Domain Layer (`packages/domain`)**:
  - `ComponentKind`: 'component' | 'controller' | 'service' | 'repository' | 'middleware' | 'handler' | 'utility'.
  - `ComponentMetadata` interface: `componentKind`, `technology`, `interfaces`, `codeRef`, `c4Level`, `c4Kind`.
  - `ComponentNodeData` interface: `label`, `componentKind`, `technology`, `interfaces`, `codeRef`, `description`, `parentId`, `componentId`.
  - Helpers: `createComponent` (`kind: 'component'`, `cmp_` ID prefix), `isComponent`.
  - Canvas projection: `projectComponentToCanvas` mapping components to React Flow canvas nodes with 220x140 dimensions, technology badges, interface tags, and code reference links.
  - 4 unit tests in `packages/domain/src/component.test.ts`.
  - Refactored `c4-component.ts` options to `CreateC4ComponentOptions` and shared predicate to avoid barrel export collisions.
- **API Layer (`apps/api`)**:
  - 6 comprehensive E2E tests in `apps/api/src/architectures/component.e2e.spec.ts` covering:
    - Component creation under a parent application (`parentId: appId`).
    - Repository Component creation under the parent application.
    - Sync connection between Service and Repository components.
    - Updating Component metadata via `PATCH /objects/:id`.
    - Architecture model snapshot reload identity (`isModelIdentical`).
    - Deletion of Component with cascading connection removal.
- **Web Client Layer (`apps/web`)**:
  - `ComponentNode` component (`apps/web/components/canvas/component-node.tsx`) rendering:
    - Component kind icons (Controller, Service, Repository, Middleware, default Component).
    - Kind badge (`[Component: Service]`, `[Component: Repository]`, etc.) with `data-testid="component-kind-badge"`.
    - Technology badge (`[...]`) with `data-testid="component-technology"`.
    - Interface chips list with `data-testid="component-interfaces"`.
    - Code reference link and inspect button with `data-testid="component-code-ref"` and `data-testid="component-code-ref-btn"`.
    - 4-way connection handles on all 4 directions.
  - Registration in `apps/web/components/canvas/custom-nodes.tsx` for `component`.
  - 7 tests in `apps/web/component.spec.ts` covering SSR node rendering, inspect callback invocation, canvas mounting with `InfiniteCanvas`, and `ArchitectureModelClient` reload identity.
