## Description
Implements **F020 — C4 Container** from Phase 03 (Architecture Model): C4 Level 2 container diagrams modeling applications, backend services, databases, and message queues inside a parent Software System (`parentId = system.id`), with inter-container connections, technology tags, and drill-down to components (DEC-001 / ADR-0001).

- **Domain Layer (`packages/domain`)**:
  - `C4ContainerKind`: 'web_app' | 'mobile_app' | 'api' | 'service' | 'database' | 'queue' | 'store'.
  - `C4ContainerNodeData` and `C4SystemBoundaryNodeData` interface definitions.
  - Helper functions: `createC4Container`, `createC4WebApp`, `createC4MobileApp`, `createC4Service`, `createC4Database`, `createC4Queue`.
  - Invariants & predicates: `isContainer`, `isContainerOfSystem`, `getSystemContainers`, `canDrillToComponents` (gated to apps/services).
  - Canvas projection bridge: `projectC4ContainerToCanvas` projecting parent system boundary and container nodes + edges.
  - Added optional `zIndex` property to `CanvasNode`.
  - 4 unit tests in `packages/domain/src/c4-container.test.ts`.
- **API Layer (`apps/api`)**:
  - Integration and persistence verification with existing `ArchitecturesService` and `ArchitecturesController`.
  - 8 comprehensive E2E tests in `apps/api/src/architectures/c4-container.e2e.spec.ts` verifying creation of containers (web app, api, database, queue) under parent system, inter-container connections (sync & async), model reload identity, and cascade/unlink handling.
- **Web Client Layer (`apps/web`)**:
  - `C4ContainerNode` component (`apps/web/components/canvas/c4-container-node.tsx`) rendering:
    - Dedicated visual themes and icons for Web App, Mobile App, API Service, Database, and Message Queue.
    - Technology tag `[Technology]` (e.g. `[TypeScript / React]`, `[PostgreSQL]`).
    - Drill-to-components button `data-testid="drill-to-components-btn"` invoking `onDrillToComponents`.
  - `C4SystemBoundaryNode` component (`apps/web/components/canvas/c4-system-boundary-node.tsx`) rendering enclosing parent system boundary with `[System Boundary: System Name]`.
  - Registration in `apps/web/components/canvas/custom-nodes.tsx` for `c4Container` and `c4SystemBoundary`.
  - 8 tests in `apps/web/c4-container.spec.ts` covering SSR node rendering, drill-to-components invocation, system boundary rendering, canvas mounting, and ArchitectureModelClient reload identity.
