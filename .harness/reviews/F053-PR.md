# PR: F053 — Permissions

## Feature Summary
Implemented pure, granular permissions system supporting 5 canonical member roles (`owner`, `admin`, `editor`, `viewer`, `guest`) with permission evaluation, strict assertions, per-workspace overrides, and per-diagram overrides. Added reusable UI components `<RoleBadge />` and `<PermissionGuard />` for conditional UI presentation.

## Acceptance Criteria Verified
- [x] Viewer cannot edit (`canPerform(viewer, 'edit_diagram') === false`).
- [x] Editor can edit (`canPerform(editor, 'edit_diagram') === true`).
- [x] Admin can invite (`canPerform(admin, 'invite_member') === true`).
- [x] Per-diagram overrides supported (viewer granted edit permission on a sandbox diagram).
- [x] Role badge and permission guard components render with correct roles, actions, and fallback states.
