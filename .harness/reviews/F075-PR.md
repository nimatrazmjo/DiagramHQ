# Pull Request: F075 — Code-to-architecture mapping

## Description
Implements bidirectional code-to-architecture mapping and traceability for DiagramHQ. Establishes deterministic links connecting C4 architecture model objects (services, components, datastores) directly to their underlying code repositories, directory folders, source file paths, and line ranges:
- Maps `ModelObject` -> repository (`provider`, `owner`, `repo`), branch/ref, folder path, file path, line numbers.
- Computes canonical remote repository deep links: "Open in GitHub" (`https://github.com/owner/repo/blob/main/path/to/file#L10-L20`) and "Open in GitLab" (`https://gitlab.com/owner/repo/-/blob/main/path/to/file#L10-20`).
- Validates repository coordinates and normalizes HTTP URLs, SSH URIs (`git@`), and project slugs.
- Injects code mapping metadata into architecture objects without violating pure model invariants.

Strict Acceptance Invariant:
- Map component -> repository -> folder -> file; open-in-GitHub / open-in-GitLab.
- Test: a component links to its repo path and generates valid remote URLs.
