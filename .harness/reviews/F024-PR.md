## Description
Implements **F024 — Application** from Phase 03 (Architecture Model): Application / Service element CRUD, rendering, parent system linkage (`parentId`), technology tagging, runtime environment metadata, component drill-down controls, and canvas projection.

- **Domain Layer (`packages/domain`)**:
  - `ApplicationType`: 'web' | 'mobile' | 'api' | 'service' | 'worker' | 'microservice' | 'serverless'.
  - `ApplicationMetadata` interface: `applicationType`, `technology`, `runtime`, `status`, `port`, `canDrillDown`, `c4Level`, `c4Kind`.
  - `ApplicationNodeData` interface: `label`, `applicationType`, `technology`, `runtime`, `status`, `port`, `description`, `canDrillDown`, `parentId`, `applicationId`.
  - Helpers: `createApplication` (`kind: 'application'`, `app_` ID prefix), `isApplication`.
  - Canvas projection: `projectApplicationToCanvas` mapping applications to React Flow canvas nodes with 240x150 dimensions, technology tags, and drill-down controls.
  - 4 unit tests in `packages/domain/src/application.test.ts`.
- **API Layer (`apps/api`)**:
  - 6 comprehensive E2E tests in `apps/api/src/architectures/application.e2e.spec.ts` covering:
    - Application service creation under a parent system (`parentId: systemId`).
    - Standalone Application service creation (`parentId: null`).
    - Sync connection between Applications.
    - Updating Application properties via `PATCH /objects/:id`.
    - Architecture model snapshot reload identity (`isModelIdentical`).
    - Deletion of Application with cascading connection removal.
- **Web Client Layer (`apps/web`)**:
  - `AppNode` component (`apps/web/components/canvas/app-node.tsx`) rendering:
    - App service icon and uppercase header.
    - Application Type tag (`[Type: ...]`) and Technology badge (`[...]`).
    - Runtime environment indicator and Port badge (`[:port]`).
    - Status indicator badge (`Active`, `Healthy`).
    - Interactive component drill-down button with custom event dispatch and callback invocation.
    - 4-way connection handles on all 4 directions.
  - Registration in `apps/web/components/canvas/custom-nodes.tsx` for `application`.
  - 5 tests in `apps/web/application.spec.ts` covering SSR node rendering, drill-down callback invocation, canvas mounting with `InfiniteCanvas`, and `ArchitectureModelClient` reload identity.
