# PR: F064 — Natural-language editing

## Feature Summary
Implemented pure AI Natural-Language Editing engine and reviewable proposal modal for DiagramHQ (Phase 08 — AI Copilot). Translates natural language editing commands (such as "add Redis between Service A and Service B", "remove Legacy Auth Proxy", or "rename Edge Gateway to Global API Gateway") into explicit, non-destructive proposed change sets:
- Explicit itemized lists of `added` (objects and connections), `modified` (object attributes and renames), and `removed` (deleted objects and disconnected incident connections) entities
- Strict invariant guarantee: AI edits are never committed silently. Every mutation is delivered as a reviewable proposal with explicit `Apply` and `Reject` user controls
- Applying validates model integrity invariants (no self-loops, endpoint existence, unique IDs) and updates live model state
- Rejecting preserves complete model immutability with optional architect rationale
- Canvas UI components `<NLEditProposalCard />` and `<NLEditModal />` with interactive prompt inputs, quick command examples, and added/modified/removed badge breakdowns
