# Pull Request: F085 — Architecture linting

## Description
Architecture linting engine and diagnostics for DiagramHQ (Phase 11 — Drift & Governance):
- Structural rules & architectural smells evaluation:
  - `ARCH-001` (Dangling Connection): Identifies connections referencing missing source or target objects.
  - `ARCH-002` (Direct Datastore-to-Datastore Coupling): Detects direct connections between two datastores that bypass application logic and break encapsulation.
  - `ARCH-003` (Invalid Containment Hierarchy): Detects missing parent containers, circular parent hierarchies, or inverted nesting (e.g. component containing an application or system).
  - `ARCH-004` (Orphaned Architecture Object): Identifies applications, components, and datastores completely isolated with zero incoming or outgoing connections.
  - `ARCH-005` (Missing Technology Stack Metadata): Flags applications and stores missing `metadata.technology` or engine definitions.
  - `ARCH-006` (Self-Referencing Connection Loop): Catches unclassified self-loops where `sourceObjectId === targetObjectId`.
  - `ARCH-007` (Excessive Node Coupling): Warns when an entity exceeds safe fan-in/fan-out thresholds, identifying potential god-services and single points of failure.
  - `ARCH-008` (Missing Entity Description): Notes components lacking human-readable architectural descriptions.
  - `ARCH-009` (Missing User/Actor Entrypoint): Reports systems lacking user personas or client entrypoints to illustrate external traffic flows.
- Findings & Categorization:
  - Severities: `error`, `warning`, `info`.
  - Categories: `structural`, `documentation`, `coupling`, `hierarchy`, `best-practice`.
  - Every finding carries target ID, target type, target name, actionable remediation advice, and diagnostic details.
  - Health score calculation (0 - 100) with weighted penalties per severity.
- Canvas UI Integration:
  - `<ArchitectureLintModal />`: Interactive modal featuring clean model hero banner with 100/100 score, health score gauge, summary KPI cards (Total Issues, Errors, Warnings, Info), severity filter tabs, category dropdown, search filtering, finding cards with actionable remediation and "Focus on Canvas" interaction, and re-scan trigger.
