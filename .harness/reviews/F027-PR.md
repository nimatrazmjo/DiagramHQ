## Description
Implements **F027 — Queue** from Phase 03 (Architecture Model): Queue element CRUD, rendering, parent application linkage (`parentId`), queue kinds (Kafka, RabbitMQ, SQS, EventBridge, PubSub, NATS, Queue), topics list, partitions, retention policy, and canvas projection.

- **Domain Layer (`packages/domain`)**:
  - `QueueKind`: 'kafka' | 'rabbitmq' | 'sqs' | 'eventbridge' | 'pubsub' | 'nats' | 'queue'.
  - `QueueMetadata` interface: `storeKind: 'queue'`, `queueKind`, `technology`, `topics`, `partitions`, `retentionPolicy`, `c4Level`, `c4Kind`.
  - `QueueNodeData` interface: `label`, `queueKind`, `technology`, `topics`, `description`, `parentId`, `queueId`.
  - Helpers: `createQueue` (`kind: 'store'`, `sto_` ID prefix), `isQueue`.
  - Canvas projection: `projectQueueToCanvas` mapping queue objects to React Flow canvas nodes with 220x130 dimensions, technology badges, topic tags, and theme-based styling.
  - 4 unit tests in `packages/domain/src/queue.test.ts`.
- **API Layer (`apps/api`)**:
  - 6 comprehensive E2E tests in `apps/api/src/architectures/queue.e2e.spec.ts` covering:
    - Queue creation under a parent application (`parentId: applicationId`).
    - Standalone Kafka cluster creation without parent (`parentId: null`).
    - Async connection between Application and Queue (`sourceObjectId: app, targetObjectId: queue`).
    - Updating Queue metadata via `PATCH /objects/:id`.
    - Architecture model snapshot reload verification (`/architectures/:id/model`).
    - Deletion of Queue with cascading connection removal.
- **Web Client Layer (`apps/web`)**:
  - `QueueNode` component (`apps/web/components/canvas/queue-node.tsx`) rendering:
    - Queue icon with theme gradient styling for Kafka, RabbitMQ, EventBridge, PubSub, SQS.
    - Kind badge (`[Queue: Kafka]`, `[Queue: RabbitMQ]`, etc.) with `data-testid="queue-kind-badge"`.
    - Technology tag (`[...]`) with `data-testid="queue-technology"`.
    - Topic chips with `data-testid="queue-topics"`.
    - 4-way connection handles on all 4 directions.
  - Registration in `apps/web/components/canvas/custom-nodes.tsx` for `queue`.
  - 4 tests in `apps/web/queue.spec.ts` covering node rendering, variant styling, and canvas projection.
