# F114 — Technology catalog

## Description
This PR implements F114 — Technology catalog, satisfying the "Technology library + tech view" feature of Phase 04.

### Changes
- Updated `Technology` schema in `apps/api/prisma/schema.prisma` and `packages/domain/src/types.ts` to include `version`, `vendor`, `lifecycle`, `securityStatus`, `owner`, and `docs`.
- Added `technology-view.ts` to `packages/domain` for projecting technology metadata to the UI canvas nodes.
- Updated `matchesViewFilter` in `packages/domain/src/view-filter.ts` to support querying by technology and technology lifecycle (`technologyLifecycle: "unsupported"`), fully addressing the F114 filtering requirements.
- Implemented `TechnologyBadges` in `apps/web/components/canvas/technology-badges.tsx` to display color-coded svg badges for an object's technologies.
- Integrated `TechnologyBadges` into `app-node.tsx`, `system-node.tsx`, `database-node.tsx`, and `component-node.tsx`.
- Updated test coverage in `packages/domain/src/view-filter.test.ts`.
