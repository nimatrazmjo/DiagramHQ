# Pull Request: F139 — Clipboard, duplicate & default marquee-select

## Overview

Implements F139 from `PHASE-14-UX-REMEDIATION.md`, bringing full canvas-convention parity with Figma/Miro:
- ⌘C copies selection (nodes + internal edges) to in-app clipboard.
- ⌘V pastes at cursor with regenerated IDs and small offset, preserving relative layout, kinds, metadata, and labels.
- ⌘D duplicates selection with offset and regenerated IDs.
- Alt-drag duplicates nodes: dragging with Alt/Option leaves the original at start position and creates a duplicate at the drop position.
- `selectionOnDrag` is enabled by default so empty canvas drag marquee-selects enclosed objects.
- Space key toggles pan mode with grab cursor.
- All actions are fully undoable and redoable via ⌘Z and ⌘⇧Z.

## Changes

### 1. In-App Clipboard & Commands (`apps/web/lib/`)
- **`canvas-clipboard.ts`**: In-app clipboard supporting nodes and internal edges (`setCanvasClipboard`, `getCanvasClipboard`, `clearCanvasClipboard`).
- **`commands/duplicate-selection-command.ts`**: Undoable command for duplicating multiple nodes and remapped internal edges via `applyCanvasUpdate`.
- **`commands/paste-selection-command.ts`**: Undoable command for pasting selections via `applyCanvasUpdate`.
- **`commands/index.ts`**: Exported new commands.
- **`canvas-store.ts`**: Set `isBoxSelectMode: true` by default.

### 2. Canvas Interactions (`apps/web/components/canvas/infinite-canvas.tsx`)
- **⌘C / Ctrl+C**: Copies selected nodes and internal edges (edges connecting two selected nodes) to clipboard.
- **⌘V / Ctrl+V**: Pastes clipboard nodes and remapped internal edges at mouse cursor or offset.
- **⌘D / Ctrl+D**: Duplicates selected nodes and internal edges.
- **Alt-Drag**: Option/Alt key detection during node and group drag preserves original position and instantiates duplicate at drop target.
- **Marquee Selection & Space Pan**:
  - `selectionOnDrag={!isSpacePanning && isBoxSelectMode}` (active by default).
  - `panOnDrag={isSpacePanning ? true : [1, 2]}`.
  - `panActivationKeyCode="Space"`.
- **Mouse Coordinate Tracking**: `onMouseMove` projects client coordinates to flow coordinates (`screenToFlowPosition`) for pasting at cursor.
- **Window Event Bridges**: `canvas:copy-selection`, `canvas:paste-selection`, `canvas:duplicate-selection`.

### 3. Tests (`apps/web/clipboard-duplicate.spec.tsx`)
- 7 comprehensive unit/integration tests:
  - In-app canvas clipboard round-tripping and clearing.
  - ⌘D duplication and ⌘Z reversion.
  - ⌘C/⌘V multi-node + internal edge round-trip, relative layout preservation, and ⌘Z reversion.
  - Alt-drag duplicate preserving original at start position and placing duplicate at drop position with ⌘Z reversion.
  - Default marquee selection state and Space key panning activation.
- Updated `apps/web/multi-select.spec.ts` and `apps/web/e2e/canvas-advanced.spec.ts` for default enabled box-select.
