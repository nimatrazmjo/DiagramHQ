# F046 — Data flows

## Description
This PR implements F046 — Data flows (Phase 05 — Flows).

Supports data-flow flow type, schema/payload attribution, and feeds data lineage (F091):
- Implements `createDataFlow()` factory setting `type: 'data_flow'`, associating overall `dataClassification` and `dataElements`.
- Enhances `FlowStep` with step-level `dataElements`, `transformation`, and `dataClassification`.
- Implements `annotateDataFlowStep()` for updating data step details while preserving step ordering and notes.
- Implements `extractDataLineage()` tracing sequential hops of data movement across architectural objects, supporting filtered queries (`searchedElement`), and detecting external egress points (`exits`) to answer "where does <data> leave our infrastructure?" (seeds F091).
- Provides `getDataFlowPlaybackStepInfo()` extracting structured step payload context for interactive playback.
- Updates canvas flow projection (`projectFlowToCanvas`) to annotate edges and flow metadata with data elements, transformation notes, and classification.
- Adds `<DataFlowOverlay />` component to render data pipeline progress, active data elements chips, transformation note, and classification pill.

### Changes

**Domain layer (`packages/domain/src/`)**
- `types.ts`: Extended `Flow` with `dataClassification`, `dataElements`; extended `FlowStep` with `dataElements`, `transformation`, `dataClassification`; added `DataLineageHop` and `DataLineageTrace` interfaces.
- `flow.ts`: Updated `createFlow`, `updateFlow`, and `addFlowStep` to map data properties; implemented `createDataFlow`, `annotateDataFlowStep`, and `extractDataLineage`.
- `flow-playback.ts`: Added `getDataFlowPlaybackStepInfo` helper for runtime step context during data flow playback.
- `flow-view.ts`: Enhanced `FlowEdgeData` and `flowMetadata` to propagate data elements, transformation notes, and classifications.
- `data-flows.test.ts`: Added 5 unit tests covering data flow creation, step annotations, step-by-step playback, lineage extraction with external exit detection, and canvas projection.

**Web layer (`apps/web/`)**
- `components/canvas/data-flow-overlay.tsx`: Added `<DataFlowOverlay />` component rendering data pipeline status, classification badges, data element pills, and transformation notes.
- `components/canvas/index.ts`: Exported `DataFlowOverlay`.
- `data-flows.spec.tsx`: Added 5 integration tests verifying data flow creation, step-by-step playback, lineage extraction, canvas projection, and UI rendering.
