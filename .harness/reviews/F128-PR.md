# Pull Request: F128 — Cost visualization

## Description
Cloud infrastructure cost estimation and architectural cost overlay engine for DiagramHQ (Phase 10 — Infrastructure Integrations):
- Attaches cloud cost data to infrastructure architecture model objects:
  - Per-resource cost model: monthly cost, hourly rate, currency (`USD`, `EUR`, `GBP`), billing period (e.g. `'2026-10'`), provider, cost breakdown (base compute, storage, data transfer, licenses, other).
  - Categorization: compute, database, storage, networking, messaging, and other.
  - Immutability: `attachCostToObject` attaches cost specs to `ModelObject.metadata.cost` without mutating the original object.
- Per-service and per-category rollups:
  - `calculateServiceCostRollup`: groups multiple resource items under the same service name, computing total monthly/hourly spend and category subtotals across compute, database, storage, and networking.
  - `calculateArchitectureCostReport`: aggregates architecture-wide monthly spend, hourly run rates, category rollups, provider distribution, and service rollups.
- Grounded billing evidence:
  - Traceable `CostEvidence` (`sourceType: 'cloud_billing'`) linking each cost item to its provider, billing account ID, meter ID, currency, and calculation timestamp.
- Canvas UI Integration:
  - `<CostVisualizationModal />`: Interactive modal featuring currency selector (`USD`, `EUR`, `GBP`), high-level KPIs (Total Monthly Spend, Hourly Run Rate, Top Cost Driver), category breakdown cards (Compute, Database, Storage, Networking, Messaging, Other), per-service cost rollup table with expandable billing evidence, and action to attach cost overlays to canvas nodes.
