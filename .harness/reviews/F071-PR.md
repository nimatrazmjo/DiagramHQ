# PR: F071 — MCP integration

## Feature Summary
Implemented pure Model Context Protocol (MCP) tool server for DiagramHQ (Phase 08 — AI Copilot). Standardizes architecture model introspection and mutation capabilities for external IDE assistants (Cursor, Claude Desktop, Antigravity) via JSON-RPC 2.0 compliant tool interfaces:
- Read / Query Tools:
  - `search_architecture`: keyword and filter queries over C4 objects, connections, and metadata
  - `get_object`: full object specifications, inbound ingress callers, and outbound dependencies
  - `get_dependencies`: returns upstream components that target depends on
  - `get_dependents`: returns downstream components depending on target
  - `analyze_impact`: calculates blast radius, affected flows, and risk levels
  - `compare_versions`: semantic visual diff across versions/branches
  - `review_change`: executes pre-merge governance checklist and returns automated review verdict
- Action / Mutation Tools (Strict Invariant: Return a proposal, never a silent commit):
  - `create_object`: returns reviewable proposal to provision new C4 component
  - `update_object`: returns reviewable proposal to modify component
  - `delete_object`: returns reviewable proposal to decommission component
  - `create_diagram`: returns reviewable proposal for new C4 projection or view
  - `create_flow`: returns reviewable proposal for new runtime flow with ordered steps
  - `create_change`: creates atomic architectural change set proposal
  - `create_adr`: drafts structured ADR proposal linked to an architecture change
- Canvas UI components `<MCPStatusBadge />` and `<MCPInspectorModal />` featuring tool catalog search, parameter schema documentation, and pending proposal review and approval workflow.
