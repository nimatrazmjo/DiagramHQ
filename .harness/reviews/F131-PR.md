# Pull Request: F131 — Compliance Packs & Regulatory Framework Mappings

## Summary
Implements comprehensive compliance packs and regulatory framework mappings for enterprise architecture governance:
- **Framework Catalog**: Built-in support for SOC 2 Type II, ISO/IEC 27001:2022, EU GDPR, HIPAA Security Rule, PCI DSS v4.0, NIST SP 800-53 Rev. 5, and CIS Controls.
- **Control Mapping Engine**: Deep domain model mapping architectural components (servers, databases, gateways, VPCs) directly to regulatory controls with attached evidence artifacts and designated owners.
- **Attestation Tracking**: Multi-state assessment pipeline (`not_started`, `in_progress`, `evidence_collected`, `under_audit_review`, `attested`).
- **Auditor Integrity Invariant**: System strictly prevents automated 'compliant' badges. Emits audit-readiness metrics, attestation percentages, and explicit auditor disclaimers (`hasAutoClaimedCompliance: false`).
- **Enterprise Web UI**: `CompliancePacksModal` component with interactive framework selector, readiness KPI cards, evidence attachment, object binding, and filterable control catalog.
