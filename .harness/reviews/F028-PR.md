## Description
Implements **F028 — Group** from Phase 03 (Architecture Model): Group/boundary element CRUD, rendering, nesting via `parentId`, cycle prevention (no group contains its ancestor), group kinds (Boundary, Zone, Team, Domain, Namespace, Group), color tagging, collapsed state, child count, and canvas projection.

- **Domain Layer (`packages/domain`)**:
  - `GroupKind`: 'group' | 'boundary' | 'zone' | 'team' | 'domain' | 'namespace'.
  - `GroupMetadata` interface: `groupKind`, `color`, `collapsed`, `c4Level`, `c4Kind`.
  - `GroupNodeData` interface: `label`, `groupKind`, `color`, `collapsed`, `childCount`, `description`, `parentId`, `groupId`.
  - Helpers: `createGroup` (`kind: 'group'`, `grp_` ID prefix), `isGroup`.
  - Canvas projection: `projectGroupToCanvas` mapping group objects to React Flow canvas nodes with 300x200 dimensions, dashed borders, child count badge, and theme-based styling.
  - 4 unit tests in `packages/domain/src/group.test.ts`.
- **API Layer (`apps/api`)**:
  - 5 comprehensive E2E tests in `apps/api/src/architectures/group.e2e.spec.ts` covering:
    - Top-level boundary group creation (`parentId: null`).
    - Nested Team group creation (`parentId: boundaryId`).
    - Nesting cycle rejection with HTTP 400 (group cannot be set to contain its ancestor).
    - Architecture model snapshot reload verification (`/architectures/:id/model`).
    - Deletion of parent group with child survival via `SetNull` cascade.
- **Web Client Layer (`apps/web`)**:
  - `GroupNode` component (`apps/web/components/canvas/group-node.tsx`) rendering:
    - Group dashed boundary styling per kind (Boundary, Zone, Team, Domain, Namespace).
    - Kind badge (`[Group: Team]`, etc.) with `data-testid="group-kind-badge"`.
    - Child count badge with `data-testid="group-child-count"`.
    - 4-way connection handles on all 4 directions.
  - Registration in `apps/web/components/canvas/custom-nodes.tsx` for `group`.
  - 4 tests in `apps/web/group.spec.ts` covering node rendering, team variant styling, and canvas projection.
