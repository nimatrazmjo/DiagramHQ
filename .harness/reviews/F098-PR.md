# F098 — PlantUML — Pull Request

## Summary
Implements bidirectional PlantUML integration for DiagramHQ: exporting architecture views into C4-PlantUML and native PlantUML component diagrams, exporting execution flows into PlantUML sequence diagrams, and importing PlantUML scripts into DiagramHQ domain models (`ModelObject`, `ModelConnection`, `FlowWithSteps`), supported by an interactive canvas UI with flavor switchers, live preview, parser diagnostics, copy, and download actions (Phase 12 — Documentation).

## Changes

### Domain (`packages/domain/src/`)
- **`plantuml.ts`**: Pure PlantUML syntax export & import engine:
  - **Sanitization & Formatting**:
    - `toPlantUmlId(rawId)`: Converts raw IDs into valid, safe PlantUML aliases (e.g. `obj_customer_123`).
    - `sanitizePlantUmlText(text)`: Escapes double quotes to single quotes and newlines to `\n`.
  - **C4 & Component Diagram Exporter (`exportViewToPlantUml`, `exportViewToPlantUmlResult`)**:
    - **C4-PlantUML Mode**:
      - Official C4-PlantUML includes (`C4_Context.puml`, `C4_Container.puml`, `C4_Component.puml`).
      - C4 Macros: `Person`, `Person_Ext`, `System`, `System_Ext`, `Container`, `ContainerDb`, `ContainerQueue`, `Component`.
      - Direction macros: `LAYOUT_TOP_DOWN()`, `LAYOUT_LEFT_RIGHT()`.
      - Boundary grouping: `System_Boundary(...) { ... }`, `Container_Boundary(...) { ... }` preserving parent hierarchies.
      - Relationships: `Rel(src, tgt, "label", "tech")`.
      - Legend: `SHOW_LEGEND()`.
    - **Native PlantUML Mode**:
      - `actor`, `database`, `queue`, `component [...] as alias`, `package "Label" { ... }`.
      - Native directional arrows (`-->`, `..>`).
    - Structured export result (`PlantUmlExportResult`) providing script, diagram type, node count, and edge count.
  - **Sequence Diagram Exporter (`exportFlowToPlantUmlSequence`)**:
    - Sequence headers `@startuml ... @enduml` with `autonumber` and title.
    - Participant and actor declarations (`actor "Label" as alias`, `participant`, `database`, `queue`).
    - Synchronous (`->`) and asynchronous (`->>`) call messages, return status codes (`-->`), and step notes (`note over`).
    - Schema annotations (`note over src, tgt : Req: ... / Res: ...`).
  - **PlantUML Importer (`importPlantUml`)**:
    - Resilient tokenizer parsing C4 macros (`Person`, `System`, `Container`, `ContainerDb`, `Rel`), boundaries (`System_Boundary`), standard components, and sequence diagrams (`actor`, `participant`, `->`, `-->`, `note over`).
    - Instantiates typed `ModelObject`, `ModelConnection`, and `FlowWithSteps` domain entities.
- **`plantuml.test.ts`**: 11 unit tests covering identifier/text sanitization, C4 context export, C4 container export with boundaries and `ContainerDb`, native component export, sequence export, C4 import, native component import, sequence diagram import, and error diagnostics.
- **`index.ts`**: Exported `plantuml`.

### Web (`apps/web/`)
- **`components/canvas/plantuml-modal.tsx`**: `<PlantUmlModal />` canvas UI:
  - Tab navigation: `Export PlantUML` and `Import PlantUML`.
  - Export controls:
    - Diagram Flavor switcher: `C4 Macro (Official Stdlib)`, `Component (Pure PlantUML)`, `Sequence (Execution Flow)`.
    - Direction buttons: `Top to Bottom`, `Left to Right`.
    - Execution flow picker for sequence diagrams.
    - Toggles: Include C4 Legend (`SHOW_LEGEND()`), Include Descriptions & Notes.
    - Live metrics summary: Target view, nodes count, relationships count.
    - Copy to clipboard with instant feedback toast.
    - Download `.puml` file action.
    - Real-time syntax-highlighted script preview pane.
  - Import controls:
    - Textarea input with quick "Load Sample C4" and "Load Sample Sequence" buttons.
    - Live parser analysis: detected diagram type, objects count, connections count, sequence steps count, syntax badge (`Valid Syntax` / `Incomplete`).
    - Discovered entity pills displaying names and architectural kinds.
    - Diagnostic error and warning alerts.
    - "Apply Import into Model" action button.
- **`components/canvas/index.ts`**: Exported `plantuml-modal`.
- **`plantuml.spec.tsx`**: 4 integration tests verifying closed modal, export tab controls and script generation, node and relationship metrics summary, and import tab parser analysis with valid syntax status and apply button.
