# F051 — Mentions

## Description
This PR implements F051 — Mentions (Phase 06 — Collaboration).

Supports @mentions in comments and descriptions with notifications, and converting a comment into a tracked task:
- Pure domain engine in `packages/domain/src/mentions.ts`:
  - `extractMentionHandles(text)`: extracts unique lowercased handles from `@username` patterns.
  - `generateMentionNotifications()`: parses comment text, matches mentioned handles against the workspace directory, excludes author self-mentions, and produces typed `MentionNotification` records.
  - `convertCommentToTask()`: converts an architectural comment into an actionable `ArchitectureTask` (`id`, `title`, `description`, `status`, `priority`, `assigneeId`, `assigneeName`, `creatorId`, `sourceCommentId`, `targetType`, `targetId`).
  - `updateTaskStatus()`: transitions tasks through `open`, `in_progress`, `completed`, and `cancelled` states, setting completion timestamps.
  - `reassignTask()`: enables reassignment to other team members.
- IDs and Branding: Added `'tsk'` and `'ntf'` prefixes and brand types (`TaskId`, `NotificationId`) to `packages/domain/src/ids.ts`.
- Web UI components in `apps/web/components/canvas/mention-task-badge.tsx`:
  - `<MentionText />`: parses text containing `@username` and renders interactive, stylized highlight pill badges (`data-testid="mention-pill-<handle>"`).
  - `<TaskCard />`: renders task cards with title, priority pill (`urgent`, `high`, `medium`, `low`), assignee indicator, target entity chip, and status toggle button.
- Comprehensive test coverage:
  - 5 unit tests in `packages/domain/src/mentions.test.ts`.
  - 4 integration tests in `apps/web/mentions.spec.tsx`.
