# F093 — Markdown Editor — Pull Request

## Summary
Implements rich model-first Markdown documentation editor with architecture embeds, diagrams, tables, code, links, mentions, and threaded comments for DiagramHQ (Phase 12 — Documentation).

## Changes

### Domain (`packages/domain/src/`)
- **`markdown-editor.ts`**: Pure markdown documentation and embedding engine:
  - **`parseMarkdownDocument(content, model, options)`**: Parses Markdown syntax, builds structured Table of Contents, extracts headings with auto-generated slugs, extracts architecture embeds (`diagram`, `object`, `flow`, `adr`, `image`), extracts entity mentions (`@object` and `@user`), and computes document stats (word count, reading time, tables count, code blocks count).
  - **Architecture Embed Directives**: Supports both fenced syntax (````diagram id: ... ````, ````object id: ... ````, ````flow id: ... ````, ````adr id: ... ````) and inline directive syntax (`:::embed:diagram[view-id]{title="..."}:::`).
  - **`validateDocumentEmbeds(doc, model)`**: Verifies embedded diagram views, objects, and flows against model entities, generating actionable validation warnings for broken references.
  - **Directive Builders**: `createDiagramEmbedDirective`, `createObjectEmbedDirective`, `createFlowEmbedDirective`, `createAdrEmbedDirective`, `insertTableMarkdown`, `insertCodeBlockMarkdown`, `insertImageMarkdown`.
  - **Semantic HTML Renderer (`renderMarkdownToHtml`)**: Renders Markdown typography, code blocks with syntax tags, tables with headers and cell formatting, images with captions, mentions with custom pill styling, and embedded architecture cards (interactive diagram view cards with "Open Diagram in Studio →", object cards with kind badge and tech stack).
  - **Document Comments (`addDocumentComment`, `resolveDocumentComment`)**: Attaches threaded comments to documents (`targetType: 'doc'`).
- **`markdown-editor.test.ts`**: 10 unit tests covering directive builders, document parser, TOC generation, embed extraction, reference validation, HTML rendering with embedded diagrams, and comment operations.
- **`index.ts`**: Exported `markdown-editor`.

### Web (`apps/web/`)
- **`components/canvas/markdown-editor-modal.tsx`**: `<MarkdownEditorModal />` canvas UI:
  - Document title input with live word counter and reading time badge.
  - View mode toggle (Split View / Edit Only / Preview Only).
  - Formatting toolbar: Headings (H2, H3), Bold, Italic, Blockquote, Lists, Table generator, Code snippet, Image embed.
  - Architecture Embed Hub: Dropdown selectors to embed diagrams/views, model objects, flows, ADRs, or entity mentions into the document.
  - Validation warning bar for broken architecture references.
  - Interactive split-pane with responsive textarea editor and live rendered preview.
  - Rendered diagram preview cards with view kind badge, title, caption, and "Open Diagram in Studio →" canvas navigation.
  - Threaded document comments sidebar with add and resolve discussion workflows.
  - Action buttons: Copy Markdown and Save.
- **`components/canvas/index.ts`**: Exported `markdown-editor-modal`.
- **`markdown-editor.spec.tsx`**: 4 integration tests covering closed modal, full toolbar and split-pane layout, document editing with embedded diagrams and tables, and embedded object cards.
