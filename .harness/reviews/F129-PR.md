# F129 — Architecture Health — Pull Request

## Summary
Implements Architecture Health Scorecard & Analytics engine for DiagramHQ (Phase 11 — Drift and Governance).

## Changes

### Domain (`packages/domain/src/`)
- **`architecture-health.ts`**: Pure architecture health evaluation engine. Aggregates 5 core categories with findings and scores:
  1. **Dependencies & Topology**: Detects cycles (via `detectDependencyCycles`), dangling connections, and isolated components.
  2. **Documentation Coverage**: Evaluates component and architecture description coverage.
  3. **Security Architecture**: Assesses exposures and compliance via `analyzeSecurityArchitecture` (F090).
  4. **Ownership Governance**: Evaluates engineering team and owner assignments across services and stores (excluding external actors/groups).
  5. **Architecture Drift**: Detects drift against actual infrastructure models via `detectArchitectureDrift` (F084).
  - Computes weighted composite health score and overall status (`healthy`, `warning`, `critical`).
  - Calculates detailed analytics counts (totalObjects, totalConnections, ownershipCoverage, documentationCoverage, cyclicDependencyCount, securityScore, driftItemCount, etc.).
  - Calculates grounded **Change Analytics** when compared against a baseline model (added/modified/removed entities, scoreDelta, trend `improving`/`degrading`/`stable`, riskLevel, and affected component/flow counts via F059 change sets).
- **`architecture-health.test.ts`**: 7 unit tests covering high score baseline, seeded gaps across all categories (cycles, missing docs, unsecured stores, unowned components, drift), and change analytics regressions/improvements.
- **`index.ts`**: Exported `architecture-health`.

### Web (`apps/web/`)
- **`components/canvas/architecture-health-panel.tsx`**: `<ArchitectureHealthModal />` — composite score indicator with status badge, 6 top-level analytics KPI cards, change analytics & trend banner, 5 interactive category cards with progress bars and score gauges, filterable findings list (by category, severity, and search term) with inspect target links, JSON export, and summary copy.
- **`components/canvas/index.ts`**: Exported `architecture-health-panel`.
- **`architecture-health.spec.tsx`**: 3 integration tests covering modal render, 5 categories breakdown, change analytics, and close state.
