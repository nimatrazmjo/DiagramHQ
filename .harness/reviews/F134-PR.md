# Pull Request: F134 — Mobile Web Companion & Desktop-First Responsive Governance

## Summary
Implements the DiagramHQ Mobile Web Companion and enforces the desktop-first architecture canvas invariant:
- **Desktop-First Canvas Invariant**: Complex 2D node drag-and-drop, multi-select alignment, and connection routing remain desktop-first (`getCanvasDisplayMode`), while mobile viewports (< 768px) automatically activate the mobile companion experience.
- **6 Mobile Workflows**:

  4. **Comments**: Threaded architectural discussions with author badges, target component tagging, and quick mobile replies (`addMobileComment`, `resolveMobileComment`).
  5. **Notifications**: Mobile notification feed tracking review requests, approvals, and comment mentions.
  6. **AI Copilot Q&A**: Mobile-optimized architectural question-and-answer prompt (`askMobileAiCopilot`) delivering high-confidence analysis and suggested actions.
- **Web UI**: Accessible `MobileCompanion` component with top ribbon, desktop-first invariant advisory, scrollable feed, and bottom mobile navigation bar.
