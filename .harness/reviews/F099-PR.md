# F099 — PDF — Pull Request

## Summary
Implements comprehensive multi-page PDF documentation compilation and export for DiagramHQ (Phase 12 — Documentation). Delivers pure TypeScript PDF 1.4 vector generation producing valid multi-page books with executive cover pages, architecture metrics, vector diagram layouts, paginated entity/service catalogs, ADR decision records, and execution flow sequences, complete with live multi-page carousel preview, print geometry controls, watermark overlays, and direct download actions.

## Changes

### Domain (`packages/domain/src/`)
- **`pdf-export.ts`**: Pure PDF 1.4 compilation engine:
  - **PDF 1.4 Structural Conformance**:
    - Compliant header `%PDF-1.4\n%\xE2\xE3\xCF\xD3\n` with binary comment indicator.
    - PDF Catalog (`/Type /Catalog`), Page Tree (`/Type /Pages /Kids [...] /Count N`), individual page objects (`/Type /Page /MediaBox [...] /Contents ... /Resources ...`), standard Helvetica/Helvetica-Bold font dictionaries, and document info dictionary (`/Title`, `/Author`, `/Creator`, `/CreationDate`).
    - Cross-reference table (`xref\n0 N ...`) with exact 10-digit byte offsets and trailer (`trailer\n<< /Size N /Root 1 0 R /Info ... >>\nstartxref\n...\n%%EOF\n`).
  - **Layout & Dimension Engine**:
    - `getPdfPageDimensions(format, orientation)` supporting standard ISO A4 (595 × 842 pt) and US Letter (612 × 792 pt) in portrait and landscape orientations.
    - PDF literal string escaping (`escapePdf`).
    - Running headers, footers with `Page X of Y` numbering, and angled watermark overlays.
  - **Multi-Page Section Generators**:
    - **Cover Page (`buildCoverPageStream`)**: Corporate branding header, title, subtitle, version badge, and metadata cards (organization, author, date, watermark).
    - **Overview Page (`buildOverviewPageStream`)**: Executive summary, key metric stat cards (systems, containers, components, databases, connections), and system partition table.
    - **Vector Diagram Pages (`buildViewPageStream`)**: Canvas boundary, automatic grid layout for elements, color-coded node boxes by kind (system, application, store, component, actor), kind badge, entity name, tech tag, and vector relationship connection lines.
    - **Entity & Service Catalog Pages (`buildCatalogPageStream`)**: Paginated multi-page table (up to 12 items/page) with entity name, kind, technology, owner, and description.
    - **Architecture Decision Records Pages (`buildAdrsPageStream`)**: Card layout with ADR title, ID, accepted/proposed status badge pills, context, decision, and consequences.
    - **Execution Flows Pages (`buildFlowsPageStream`)**: Transaction step table mapping sequence numbers, source entities, target entities, operations/endpoints, and notes.
  - **Export Book Helpers (`exportArchitecturePdfBook`, `exportDocumentToPdf`)**:
    - Compiles full PDF 1.4 document into binary string, generates base64 data URI, calculates page count, dimensions, byte size, sanitized filename, and FNV-1a checksum.
- **`pdf-export.test.ts`**: 9 unit tests covering page dimensions calculation across formats/orientations, full multi-page book generation, selective section export, vector diagram box rendering, catalog table multi-page wrapping, ADR and flow rendering, special character escaping, and single view export.
- **`index.ts`**: Exported `pdf-export`.

### Web (`apps/web/`)
- **`components/canvas/pdf-export-modal.tsx`**: `<PdfExportModal />` canvas UI:
  - Tab navigation: `Live Preview`, `Document Sections & Options`, and `PDF Syntax Inspector`.
  - Live Preview tab:
    - Interactive page carousel navigation buttons (`Page 1`, `Page 2`, ...) with current page indicator.
    - High-fidelity visual sheet preview in landscape/portrait geometry.
    - Dynamic section renderer matching cover page, architecture diagrams, and catalogs.
    - Watermark overlay and running headers/footers with dynamic page numbers.
  - Document Sections & Options tab:
    - Checkbox toggles for 6 document sections: Cover Page, Overview & Metrics, Architecture Diagrams, Entity & Service Catalog, Decision Records (ADRs), Execution Flows & Sequences.
    - Geometry controls: Page format (A4, Letter), orientation (Landscape, Portrait), page number toggle.
    - Metadata inputs: Custom title, author/team, organization, and watermark text.
  - PDF Syntax Inspector tab:
    - Raw stream viewer displaying `%PDF-1.4` objects, streams, XREF, and trailer.
  - Modal Footer:
    - Live file size and page count badges.
    - "Copy Data URI" action with copied feedback.
    - "Download PDF Book" action creating and triggering browser download.
- **`components/canvas/index.ts`**: Exported `pdf-export-modal`.
- **`pdf-export.spec.tsx`**: 4 integration tests verifying closed modal state, modal dialog rendering with header and action buttons, multi-page carousel controls, and document metadata preview.
