# PR: F054 — Team management

## Feature Summary
Implemented pure team management and object ownership domain logic. Supports team lifecycle (creation, slug derivation, member management, team leads), object ownership attachment (primary owner team, backup owner team, contact leads), and filtering architecture models/objects by owner team ("show everything owned by X"). Added UI components `<TeamBadge />` and `<OwnershipFilterSelector />`.

## Acceptance Criteria Verified
- [x] Teams management: `createTeam`, `addTeamMember`, `removeTeamMember`, `setTeamLead`, `isTeamMember`.
- [x] Object ownership: `assignObjectOwnership`, `getObjectOwnership`, supporting primary and backup teams.
- [x] "Show everything owned by X": `filterObjectsByOwner` and `filterModelByOwner` filter objects and intra-team connections.
- [x] Optional backup team ownership matching with `includeBackup: true`.
- [x] UI components `<TeamBadge />` and `<OwnershipFilterSelector />` with primary/backup tags and team filtering dropdown.
