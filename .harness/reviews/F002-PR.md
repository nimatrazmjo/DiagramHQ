## Summary of Changes

Implements **F002 — Authentication** from Phase 01 (Foundation):
- **Architecture Decision (DEC-007)**: Selected Auth.js (NextAuth v5) for web authentication and stateless JWT validation across web and api using a shared `AUTH_SECRET`. Zero external SaaS dependencies required for local development and CI testing.
- **Shared Domain Types (`packages/domain`)**:
  - Registered `usr_` prefix in `IdPrefix`.
  - Added framework-free `User`, `AuthSessionUser`, and `AuthTokenPayload` interfaces.
- **Web Application (`apps/web`)**:
  - Configured NextAuth v5 (`auth.config.ts`, `auth.ts`, `app/api/auth/[...nextauth]/route.ts`) with Credentials provider and JWT session strategy.
  - Added edge `middleware.ts` for route protection redirecting unauthenticated requests from `/dashboard` to `/login?callbackUrl=...`.
  - Implemented `/login` form with modern web autofill best practices (`autocomplete="username"`, `autocomplete="current-password"`).
  - Implemented `/dashboard` protected page with session display and sign-out action.
  - Added unit test suite in `auth.spec.ts`.
- **API Application (`apps/api`)**:
  - Implemented `AuthModule`, `AuthService`, `AuthGuard`, `@CurrentUser()`, and `@Public()` decorators.
  - Added `POST /auth/token` (credential verification and token signing) and `GET /auth/me` (stateless token authentication).
  - Returns standard structured error envelope (`{ error: { code: 'UNAUTHORIZED', message: ... } }`) on missing/invalid/expired tokens.
  - Added unit tests for `AuthService` (5 tests) and `AuthGuard` (5 tests).
  - Added end-to-end integration tests in `auth.e2e.spec.ts` (6 tests) exercising the real HTTP pipeline and NestJS DI container.
- **Harness & Config**:
  - Updated `packages/config/eslint-preset.js` to allow decorator-based DI in NestJS guards, filters, pipes, and interceptors.
  - Added `AUTH_SECRET` and `NEXTAUTH_URL` to `.env.example`.
