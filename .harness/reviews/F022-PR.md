## Description
Implements **F022 — Person** from Phase 03 (Architecture Model): Person / Actor element CRUD, rendering, role/department/external metadata, and canvas projection.

- **Domain Layer (`packages/domain`)**:
  - `PersonMetadata` interface: role, department, external status flag, email, and extensible metadata.
  - `PersonNodeData` interface: label, role, department, external status, email, and description.
  - Helpers: `createPerson` (`kind: 'actor'`, `act_` ID prefix), `isPerson`, `isExternalPerson`.
  - Canvas projection: `projectPersonToCanvas` mapping person model objects to React Flow canvas nodes with complete persona attributes.
  - 4 unit tests in `packages/domain/src/person.test.ts`.
- **API Layer (`apps/api`)**:
  - 7 comprehensive E2E tests in `apps/api/src/architectures/person.e2e.spec.ts` covering:
    - Internal Person creation with role, department, and email.
    - External Person creation (customers/external actors).
    - Connecting Person to Software System with relationship kind and label.
    - Updating Person metadata via PATCH `/objects/:id`.
    - Snapshot reload identity (`isModelIdentical`).
    - Deletion of Person with cascading connection removal.
- **Web Client Layer (`apps/web`)**:
  - `PersonNode` component (`apps/web/components/canvas/person-node.tsx`) rendering:
    - Person avatar icon and uppercase header.
    - Role badge (`[Role: ...]`) and Department tag (`[Dept: ...]`).
    - Internal vs External actor badges with distinctive styling.
    - Contact email with mail icon.
    - 4-way connection handles on all sides (source and target).
    - Selected ring states and dashed border for external personas.
  - Registration in `apps/web/components/canvas/custom-nodes.tsx` for `person` and `actor`.
  - 5 tests in `apps/web/person.spec.ts` covering SSR node rendering, external persona badge, selected ring, canvas mounting with `InfiniteCanvas`, and `ArchitectureModelClient` reload identity.
