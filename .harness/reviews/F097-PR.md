# F097 — Mermaid — Pull Request

## Summary
Implements bidirectional Mermaid.js integration for DiagramHQ: exporting architecture views into Mermaid flowcharts and execution flows into sequence diagrams, as well as importing Mermaid flowchart scripts and sequence diagrams into DiagramHQ domain models (`ModelObject`, `ModelConnection`, `FlowWithSteps`), supported by interactive canvas UI with live script preview, parser diagnostics, copy, and download actions (Phase 12 — Documentation).

## Changes

### Domain (`packages/domain/src/`)
- **`mermaid.ts`**: Pure Mermaid syntax export & import engine:
  - **Syntax Sanitization & Formatting**:
    - `toMermaidId(rawId)`: Converts raw IDs into safe alphanumeric Mermaid identifiers.
    - `sanitizeMermaidLabel(text)`: Sanitizes labels and titles, escaping newlines and quotes.
    - `formatMermaidNodeShape(id, name, kind)`: Renders specific node shapes per C4 kind:
      - `store` -> cylinder `[(...)]`
      - `actor` -> stadium `([ ... ])`
      - `component` -> subroutine `[[ ... ]]`
      - default (`system`, `application`, etc.) -> rounded rectangle `[...]`
  - **Flowchart Exporter (`exportViewToMermaidFlowchart`, `exportViewToMermaid`)**:
    - Exports any architecture view to Mermaid flowchart with direction (`TB`, `TD`, `LR`, `RL`).
    - Subgraph grouping by parent hierarchy (e.g. system subgraphs containing applications and stores).
    - Edge arrow formatting based on connection kind (`-->`, `-.->`, `==>`) with label annotations.
    - Class definitions (`classDef`) with dark-theme color styling for system, application, store, component, and actor.
    - Returns structured `MermaidExportResult` with script, node count, and edge count.
  - **Sequence Diagram Exporter (`exportFlowToMermaid`, `exportFlowToMermaidResult`)**:
    - Exports execution flows into Mermaid sequence diagram syntax.
    - Participant and actor declarations (`participant A as Label`, `actor User as Customer`).
    - Synchronous (`->>`) and asynchronous (`-->>`) arrows with step message notes, HTTP methods, and status returns.
    - Notes over participants for step documentation and schemas.
  - **Flowchart Importer (`importMermaidFlowchart`)**:
    - Parses Mermaid flowchart script lines, extracting subgraphs, node definitions with shapes and labels, and connection edges with arrow styles and labels.
    - Creates corresponding `ModelObject` records with appropriate kinds (`system`, `application`, `store`, `component`, `actor`) and `ModelConnection` records.
  - **Sequence Importer (`importMermaidSequence`)**:
    - Parses Mermaid sequence diagram scripts, extracting actors, participants, notes, and messages.
    - Constructs `ModelObject` participants, `ModelConnection` edges, and `FlowWithSteps` sequence with indexed `FlowStep` records.
- **`mermaid.test.ts`**: 8 comprehensive unit tests covering:
  - Identifier and label sanitization.
  - Node shape formatting.
  - Flowchart export with subgraphs and styling.
  - Sequence diagram export with participants and message steps.
  - Flowchart import into model objects and connections.
  - Sequence diagram import into flow steps and participants.
  - Robust error handling for invalid or empty scripts.
- **`index.ts`**: Exported `mermaid`.

### Web (`apps/web/`)
- **`components/canvas/mermaid-modal.tsx`**: `<MermaidModal />` canvas UI:
  - Tab navigation: `Export Mermaid` and `Import Mermaid`.
  - Export controls:
    - Diagram type switcher: Flowchart vs Sequence.
    - Flowchart direction buttons: `TB`, `TD`, `LR`, `RL`.
    - Execution flow selector for sequence diagrams.
    - Options: Include Subgraphs, Include Notes & Descriptions.
    - Live metrics summary: Target view, node count, edge count.
    - Copy to clipboard with instant feedback toast.
    - Download `.mmd` file action.
    - Real-time syntax-highlighted script preview pane.
  - Import controls:
    - Textarea for Mermaid scripts with quick "Load Sample Flowchart" and "Load Sample Sequence" buttons.
    - Live parser analysis pane showing detected diagram type, object count, connection count, and step count.
    - Discovered entity pills displaying names and architectural kinds.
    - Real-time syntax validation status badge (`Valid Syntax` / `Incomplete`).
    - Error and warning diagnostic alerts.
    - "Apply Import into Model" action button.
- **`components/canvas/index.ts`**: Exported `mermaid-modal`.
- **`mermaid.spec.tsx`**: 4 integration tests verifying closed modal, export tab controls and script generation, node and connection metrics summary, and import tab parser analysis with valid syntax status and apply button.
