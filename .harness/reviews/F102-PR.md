# F102 — SAML — Pull Request

## Summary
Implements Enterprise SAML 2.0 Web Browser Single Sign-On (SSO) assertion flow and metadata exchange for DiagramHQ (Phase 13 — Enterprise). Delivers pure TypeScript domain logic for Service Provider (SP) metadata generation (`EntityDescriptor`), Identity Provider (IdP) metadata parsing, AuthnRequest generation with Base64 encoding and HTTP-Redirect bindings, SAML 2.0 Response & Assertion condition verification (InResponseTo CSRF mitigation, Issuer matching, NotBefore/NotOnOrAfter time validity windows with clock skew tolerance, and AudienceRestriction checks), Subject NameID and AttributeStatement extraction, group-to-role attribute mapping to DiagramHQ `MemberRole`, Just-In-Time (JIT) provisioning, and a deterministic Test SAML IdP simulation engine. Integrates SAML 2.0 authentication into NextAuth, the Web login interface, and the Enterprise SSO settings modal with live SP metadata copy, IdP XML parsing, and 1-click assertion simulation.

## Changes

### Domain (`packages/domain/src/`)
- **`ids.ts`**: Added `saml` prefix to `IdPrefix` union and created branded type `SamlRequestId`.
- **`saml.ts`**: Pure TypeScript SAML 2.0 integration engine:
  - **Service Provider (SP) Metadata (`buildSpMetadataXml`)**:
    - Generates W3C-compliant XML metadata with EntityID, AssertionConsumerService (`HTTP-POST` ACS URL), SingleLogoutService (`HTTP-POST` SLO URL), and NameIDFormat (`urn:oasis:names:tc:SAML:1.1:nameid-format:emailAddress`).
  - **IdP Metadata Parsing (`parseIdpMetadataXml`)**:
    - Parses XML metadata from corporate identity providers (Okta, Microsoft Entra ID, PingIdentity, OneLogin) to extract EntityID, SingleSignOnService Location, SingleLogoutService Location, and X.509 certificates.
  - **AuthnRequest Generator (`buildSamlAuthnRequest`)**:
    - Builds signed `<samlp:AuthnRequest>` XML with unique `saml_` request IDs, IssueInstant, Destination, ProtocolBinding, SP Issuer, and NameIDPolicy.
    - Base64 encodes payloads and constructs HTTP-Redirect URLs with `SAMLRequest` and `RelayState` parameters.
  - **Response & Assertion Validator (`parseAndValidateSamlResponse`)**:
    - Decodes Base64 XML `<samlp:Response>` and validates `<samlp:StatusCode>`.
    - Enforces security conditions: InResponseTo match (CSRF protection), Issuer match, NotBefore/NotOnOrAfter validity window with clock skew tolerance, and AudienceRestriction match.
    - Extracts Subject `<saml:NameID>` and attributes (`email`, `displayName`, `firstName`, `lastName`, `memberOf`, `groups`).
    - Maps attributes to `MemberRole` using `roleMapping` (defaulting to `editor`, `admin`, or `viewer`).
    - Provisions JIT user identities with branded `usr_` IDs or links existing accounts.
    - Issues authenticated 8-hour `SsoAuthSession`.
  - **Deterministic Test SAML IdP Simulation (`createTestSamlIdpConfig`, `buildTestSamlResponseXml`, `simulateTestSamlLogin`)**:
    - Enables end-to-end SAML 2.0 assertion flow testing without remote network calls.
- **`saml.test.ts`**: 17 unit tests verifying SP metadata generation, IdP metadata parsing, AuthnRequest generation, assertion validation, condition/clock skew verification, error statuses, CSRF InResponseTo checks, Issuer and Audience mismatch rejections, JIT provisioning, existing account linking, and full Test IdP simulation.
- **`index.ts`**: Exported `saml`.

### Web (`apps/web/`)
- **`auth.config.ts`**: Added SAML 2.0 authentication handling in `authorizeUser`, connecting SAML credentials to `simulateTestSamlLogin` and populating session provider metadata (`Acme Enterprise SAML 2.0 IdP`).
- **`auth.spec.ts`**: Added test case verifying enterprise SAML 2.0 assertion authentication flow.
- **`components/enterprise/sso-settings-modal.tsx`**:
  - Added `SAML 2.0 SP Config` tab displaying Service Provider Entity ID, ACS URL, and SLO URL with 1-click clipboard copy.
  - Added interactive IdP Metadata XML importer with real-time parsing (`parseIdpMetadataXml`).
  - Added SAML 2.0 simulation action button in the `Test Simulation` tab.
- **`app/login/login-form.tsx`**: Added 1-Click "⚡ Sign In with SAML 2.0 (Acme IdP)" quick authentication button.
- **`saml.spec.tsx`**: 5 integration tests verifying SP metadata generation, IdP XML parsing, LoginForm SAML action button, SsoSettingsModal SAML tab, and end-to-end SAML assertion exchange.
