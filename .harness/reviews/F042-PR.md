# F042 — Flow steps

## Description
This PR implements F042 — Flow steps (Phase 05 — Flows).

Provides granular operations on flow steps: adding steps at specific positions or appending, annotating steps with descriptive notes, reordering steps by index or explicit list, and deleting steps, ensuring step ordering and annotations persist reliably.

### Changes

**Domain layer (`packages/domain/src/`)**
- Added step manipulation functions in `flow.ts`:
  - `addFlowStep(flow, stepInput, insertAtIndex?, availableConnections?)` — inserts step, shifts subsequent indices, validates connection references
  - `removeFlowStep(flow, stepIdOrIndex)` — removes step and re-normalizes indices
  - `annotateFlowStep(flow, stepIdOrIndex, note)` — adds/updates note while preserving order and notes on other steps
  - `reorderFlowStepsByIndex(flow, fromIndex, toIndex)` — moves step and normalizes sequence
  - `reorderFlowStepList(flow, orderedStepIds)` — re-sequences steps per explicit ID array
- Added 5 unit tests in `flow.test.ts` verifying insertion, index shifting, note persistence, removal, index reordering, and ID-based reordering.

**API layer (`apps/api/src/`)**
- Added DTOs in `flows.dto.ts`: `AddFlowStepDto`, `UpdateFlowStepDto`, `ReorderFlowStepsDto`
- Added methods in `flows.service.ts`:
  - `addStep(userId, flowId, dto)`
  - `updateStep(userId, flowId, stepId, dto)`
  - `removeStep(userId, flowId, stepId)`
  - `reorderSteps(userId, flowId, dto)`
- Added endpoints in `flows.controller.ts`:
  - `POST /flows/:flowId/steps`
  - `PATCH /flows/:flowId/steps/:stepId`
  - `DELETE /flows/:flowId/steps/:stepId`
  - `PUT /flows/:flowId/steps/reorder`
- Added 5 unit tests in `flows.service.spec.ts`.

**Web layer (`apps/web/`)**
- Added integration suite in `flow-steps.spec.ts` (4 tests) verifying adding, inserting in the middle, annotating, reordering by index and list, and note persistence.
