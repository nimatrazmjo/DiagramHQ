# Pull Request: F124 — Database catalog

## Description
Database catalog for DiagramHQ. Enables architectural discovery, documentation, and schema governance of relational and non-relational datastores across distributed systems:
- Hierarchical structure: Database Instance -> Schema/Namespace -> Table/Collection -> Column/Field.
- Captures full database engine types: PostgreSQL, MySQL, SQLite, MongoDB, Redis, DynamoDB, Cassandra, ClickHouse, Snowflake, BigQuery.
- Rich column attributes: Primary keys, foreign key constraints (`targetTable`, `targetColumn`, `onDelete`, `onUpdate`), nullability, default values, indices (unique, compound, B-Tree, hash), and data classification tags (PII, financial, internal).
- Deterministically links database nodes to C4 model components/datastores (`ObjectId`) and source code migration locations (`CodeLocationSpec`).
- Supports multi-dimensional search and schema browsing across databases, tables, columns, and foreign key relationships.
