# Pull Request: F125 — Model-as-code + CLI

## Description
Model-as-code serialization engine and `dhq` CLI command surface for DiagramHQ. Enables architectural specifications to be defined, versioned, validated, and synchronized directly as human-readable YAML:
- Bidirectional YAML serialization mapping objects and connections by human-readable, deterministic `slug` to stable internal IDs (`ObjectId`, `ConnectionId`).
- Supports C4 model object kinds (`actor`, `system`, `application`, `store`, `component`) with aliases (`person`, `container`, `database`).
- Implements comprehensive `dhq` CLI command surface: `dhq login`, `dhq init`, `dhq pull`, `dhq push`, `dhq validate`, `dhq diff`, `dhq deploy`, `dhq export`, `dhq generate`.
- Push-then-pull round-trip fidelity: parsing YAML into domain model and pulling model back into YAML produces equivalent semantic structures without loss.
- Validation: catches syntax errors, duplicate slugs, dangling connection references, unknown parents, and parent hierarchy cycles.
- Diff engine: compares YAML documents or local YAML against remote model, computing structural additions, removals, and modifications.
