## Summary of Changes

### F141 — Unify to one canvas (Phase 14 — UX Remediation)

This PR collapses multiple disparate canvas surfaces into a single, unified architecture editor (`InfiniteCanvas` built on React Flow), eliminating the hand-rolled SVG canvas, resolving conflicting zoom clusters, and eliminating panel collisions.

#### 1. Single Canvas Editor Implementation
- Deleted hand-rolled SVG canvas (`apps/web/app/canvas/[workspaceId]/[diagramId]/page.tsx`) and the entire `apps/web/app/canvas/` directory.
- Configured Next.js server redirects in `apps/web/next.config.mjs` routing `/canvas/:path*` directly to `/studio`.
- Updated all links across workspace pages (`systems`, `data`, `apps`, `views`) to navigate directly to `/studio` (and `/studio?viewId=...`), establishing a consistent mental model across all navigation entry points.
- Upgraded the embedded workspace overview canvas (`apps/web/app/workspace/[workspaceId]/page.tsx`) to host the fully-featured `InfiniteCanvas` editor with shape palette and template picker enabled.
- Result: **Exactly 1 canvas editor implementation** remains in the entire codebase.

#### 2. Unified Zoom Cluster & Collision-Free Panel Layout
- Dropped React Flow's native `<Controls>` component from `apps/web/components/canvas/infinite-canvas.tsx`, eliminating redundant zoom controls and removing the bottom-left hit target collision.
- Positioned the custom pan/zoom toolbar (`data-testid="pan-zoom-toolbar"`) in `Panel position="bottom-right"` (following Figma / Miro conventions) as the single source of zoom/pan truth.
- Gave `LayoutMenu` (`data-testid="layout-menu"`) its own dedicated `Panel position="bottom-left"` corner with zero overlapping elements.
- Positioned `<MiniMap>` in `bottom-right` above the pan-zoom toolbar, with `hidden sm:block` to keep mobile screens uncluttered.
- Added responsive styling (`max-w-[calc(100vw-110px)]` and `flex-wrap sm:flex-nowrap`) and raised `AlignmentToolbar` (`mb-14 sm:mb-3`), ensuring zero panel overlap down to 400px mobile phone widths.

#### 3. Automated Tests
- Added `apps/web/one-canvas.spec.tsx` (6 tests) verifying:
  - Deletion of hand-rolled SVG canvas file and directory.
  - Next.js config `/canvas/:path*` redirects to `/studio`.
  - Workspace sub-pages route links to `/studio`.
  - Workspace overview renders unified `InfiniteCanvas` with toolbar and palette.
  - Native React Flow `Controls` are absent.
  - Single zoom cluster renders at bottom-right, layout menu at bottom-left, with responsive non-overlapping width bounds.
