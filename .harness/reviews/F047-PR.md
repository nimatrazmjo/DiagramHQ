# F047 — API flows

## Description
This PR implements F047 — API flows (Phase 05 — Flows, final feature completing Phase 05).

Supports API-request flow type (`kind: 'api_flow'`, HTTP method, endpoint, request/response schema, status code) and sequence diagram exporters to Mermaid and PlantUML:
- Implements `createApiFlow()` factory setting `type: 'api_flow'`, validating non-empty endpoint, associating `endpoint`, `httpMethod` (normalized to uppercase), `requestSchema`, `responseSchema`, and `statusCode`.
- Enhances `FlowStep` with step-level `endpoint`, `httpMethod`, `requestSchema`, `responseSchema`, and `statusCode`.
- Implements `annotateApiFlowStep()` for updating API step metadata and notes.
- Implements `exportFlowToMermaidSequence()` exporting API flow sequences to valid Mermaid sequence diagrams (`sequenceDiagram`, `autonumber`, participant aliases, actor participant for actors, call arrows with method and endpoint, request/response schema notes, and return arrows with HTTP status codes).
- Implements `exportFlowToPlantUMLSequence()` exporting API flow sequences to valid PlantUML sequence diagrams (`@startuml`, `title`, `autonumber`, `actor "..." as ...`, participant declarations, `->` request calls, `-->` return arrows with status codes, `@enduml`).
- Provides `getApiFlowPlaybackStepInfo()` extracting structured step API context for interactive playback.
- Updates canvas flow projection (`projectFlowToCanvas`) to annotate edges and flow metadata with endpoint, method, status code, and schemas.
- Adds `<ApiFlowOverlay />` component rendering API endpoint, method badge with method-specific color schemes, status code pill, progress bar, step note, request/response schema code blocks, and quick exporter action buttons (Export Mermaid / Export PlantUML).

### Changes

**Domain layer (`packages/domain/src/`)**
- `types.ts`: Extended `Flow` and `FlowStep` with `endpoint`, `httpMethod`, `requestSchema`, `responseSchema`, `statusCode`; added `SequenceDiagramExportOptions` interface.
- `flow.ts`: Updated `createFlow`, `updateFlow`, and `addFlowStep` to map API fields; implemented `createApiFlow`, `annotateApiFlowStep`, `exportFlowToMermaidSequence`, and `exportFlowToPlantUMLSequence`.
- `flow-playback.ts`: Added `getApiFlowPlaybackStepInfo` helper for runtime step context during API flow playback.
- `flow-view.ts`: Enhanced `FlowEdgeData` and `flowMetadata` to propagate API endpoint, method, status code, schemas, and active step variants.
- `api-flows.test.ts`: Added 9 unit tests covering API flow creation, step annotations, playback context extraction, Mermaid sequence export, PlantUML sequence export, missing connection validation, and canvas projection.

**Web layer (`apps/web/`)**
- `components/canvas/api-flow-overlay.tsx`: Added `<ApiFlowOverlay />` component rendering API details, method badges, status code pills, schema previews, and export action buttons.
- `components/canvas/index.ts`: Exported `ApiFlowOverlay`.
- `api-flows.spec.tsx`: Added 6 integration tests verifying API flow instantiation, playback tracking, Mermaid export, PlantUML export, canvas projection, and overlay UI rendering.
