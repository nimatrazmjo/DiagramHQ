# F049 — Presence

## Description
This PR implements F049 — Presence (Phase 06 — Collaboration).

Supports real-time multi-user presence, animated cursors, remote selection, current-object indicators, and peer avatars:
- Implements pure presence domain model (`packages/domain/src/presence.ts`):
  - `UserPresence`: tracks `userId`, `userName`, `userColor`, `avatarUrl`, `role`, `status` ('active' | 'idle' | 'offline'), `cursor` (`CursorPosition`), `selectedObjectIds`, `selectedConnectionIds`, `currentObjectId`, `currentViewId`, and `lastHeartbeatAt`.
  - `createPresenceRoom()`: initializes presence state machine for a workspace.
  - `upsertPeerPresence()`: registers or updates peer metadata without dropping active selections or views.
  - `updatePeerCursor()`: updates peer coordinates, active view, and refreshes heartbeat.
  - `updatePeerSelection()`: tracks multi-node selection and active object focus.
  - `removePeerPresence()`: cleanly removes peer state upon disconnection.
  - `pruneInactivePeers()`: marks peers idle after timeout (default 30s) and prunes disconnected peers after offline timeout (default 60s).
  - `getRemoteCursorsForView()`: filters remote cursors matching the active diagram view.
  - `getRemoteSelections()`: aggregates multi-peer object selection maps (`objectId -> PeerIdentity[]`).
  - `getRemoteActiveObjects()`: aggregates current-object focus maps (`objectId -> PeerIdentity[]`).
- Implements canvas UI components (`apps/web/components/canvas/`):
  - `<PresenceCursors />`: SVG arrow pointers colored with `userColor`, name pills, active object badge, and multi-selection count indicator.
  - `<PresenceIndicators />`: Live pulse indicator, collaborator count, colored avatar chips with initials, idle/active indicator rings, hover tooltips with object/view context, and overflow badge (`+N`).
- Integration and unit test coverage:
  - 8 unit tests in `packages/domain/src/presence.test.ts`.
  - 6 integration tests in `apps/web/presence.spec.tsx`.
