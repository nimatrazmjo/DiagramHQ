## Description
Implements **F017 — Minimap** from Phase 02 (Canvas): a canvas overview minimap, viewport navigation, full-screen mode, and focus mode with keyboard shortcuts and toolbar controls.

- **Minimap Overview & Viewport Indicator**:
  - Embedded `<MiniMap>` from `@xyflow/react` rendered conditionally based on `isMinimapVisible` state.
  - Custom node coloring (`getMiniMapNodeColor`) reflecting architectural element types (system, app/container, store/database, component, person) with blue accent for selected nodes.
  - Interactive viewport indicator with pannable/zoomable click-to-navigate support.
- **Full-Screen Canvas Mode**:
  - Integrates with standard browser HTML5 Fullscreen API (`requestFullscreen` / `exitFullscreen`) on the canvas container element with robust fallback.
  - Synchronizes fullscreen state (`isFullscreen`) via fullscreenchange events.
  - Fullscreen toggle button on the bottom-right canvas controls and keyboard shortcut <kbd>Shift</kbd>+<kbd>F</kbd>.
- **Focus Mode**:
  - Focus Mode isolates selected nodes and their immediate context by dimming unselected elements (opacity 0.15, grayscale).
  - Prominent top-left indicator badge (`data-testid="focus-mode-badge"`) displayed when active.
  - Focus Mode toggle button in the canvas controls and keyboard shortcut <kbd>Alt</kbd>+<kbd>F</kbd> (or exiting via <kbd>Escape</kbd>).
- **Zustand Transient State & Layer Boundary Integrity**:
  - Added transient UI flags (`isMinimapVisible`, `isFullscreen`, `isFocusMode`) to `canvas-store.ts`.
  - Maintained strict conformance with Layer Boundary Rule 4 (Zustand holds no domain entities, only transient UI state). Whitelist verified in `canvas.spec.ts`.
