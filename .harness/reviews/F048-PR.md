# F048 — Real-time collaboration

## Description
This PR implements F048 — Real-time collaboration (Phase 06 — Collaboration, first feature kicking off Phase 06).

Supports real-time architecture model synchronization using a pure deterministic conflict-free replication / operational transformation (CRDT / LWW) engine:
- Implements `CollabOperation` union type supporting:
  - `upsert_object`: adding or updating architecture model objects with Lamport-stamped metadata
  - `delete_object`: removing architecture model objects and cascading deletions across connected connections and diagram view coordinates
  - `upsert_connection`: adding or updating architecture connections
  - `delete_connection`: removing architecture connections
  - `update_object_position`: updating diagram view positions with deterministic multi-peer synchronization
- Implements `compareLamport()` deterministic tie-breaker (higher Lamport clock wins; deterministic session ID lexical sorting breaks identical timestamp ties).
- Implements `createCollabSession()`, `applyLocalOperation()`, `applyRemoteOperation()`, and `syncSessions()`.
- Implements cascade deletion across objects, connections, and view coordinates to guarantee integrity under concurrent operations.
- Adds `<CollaborationBanner />` UI component rendering live pulse status, peer count, avatar chips, operation counter, LWW conflict resolution indicator, and manual sync action.
