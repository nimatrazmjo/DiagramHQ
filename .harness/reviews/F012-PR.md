## Description
Implements **F012 — Drag and drop** from Phase 02 (Canvas):
- Drag objects on the canvas to reposition them.
- Position updates persist in the view layout state via the client-model command layer (ADR-0002 / Layer Boundary Rule 3).
- Strict layer boundary compliance: canvas components never issue direct HTTP requests; they dispatch `MoveNodeCommand` to `CommandDispatcher`.
- NestJS API endpoint `PATCH /views/:viewId/objects/:objectId/position` updates and persists layout positions in PostgreSQL `view_objects` table.
- Multi-tenancy and authorization enforced with `canWrite` role guard; viewers receive 403 Forbidden.
