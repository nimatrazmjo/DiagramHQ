## Summary of Changes

### F140 — IA cleanup: hide plumbing, one brand, honest copy (Phase 14 — UX Remediation)

This PR resolves Information Architecture (IA) and branding inconsistencies across DiagramHQ, eliminating internal plumbing leaks, establishing unified brand naming, and rewriting outdated landing page copy.

#### 1. Hide Internal Model Plumbing
- **Dashboard (`apps/web/app/dashboard/page.tsx`)**: Replaced primary display of raw user ID, organization slug, and organization ID with an intuitive overview, prominent "Open Studio" CTA button, and tucked raw identifiers into a collapsible developer details affordance (`<details data-testid="dev-session-details">` / `data-testid="dev-org-details"`).
- **Workspace (`apps/web/app/workspace/[workspaceId]/page.tsx`)**: Replaced raw workspace UUID in the header with a human-readable title ("Architecture model and diagram projections"), added an "Open Studio" CTA, and tucked the raw workspace ID into `<details data-testid="dev-workspace-details">`.
- Result: **0 raw IDs/slugs** exposed on default dashboard or workspace views.

#### 2. Single Brand Name ("DiagramHQ")
- Unified brand identity across all surfaces:
  - Header branding on `/dashboard`: "DiagramHQ"
  - Left navigator footer (`apps/web/components/shell/left-navigator.tsx`): "DiagramHQ"
  - Workspace layout metadata description (`apps/web/app/workspace/[workspaceId]/layout.tsx`): "DiagramHQ Architecture Studio"
  - PDF export running headers (`apps/web/components/canvas/pdf-export-modal.tsx`): "DiagramHQ"
  - E2E auth test assertions (`apps/web/e2e/auth.spec.ts`): "DiagramHQ"

#### 3. Honest Landing Copy & Primary CTA
- **Landing Page (`apps/web/app/page.tsx`)**: Rewrote hero copy, navigation, and feature sections to eliminate stale "Phase 02" promises. Primary CTA now directly opens DiagramHQ Studio (`/studio`).

#### 4. Automated Tests
- Added `apps/web/ia-cleanup.spec.tsx` with 4 unit/integration tests verifying:
  - Landing copy is honest and free of "Phase 02".
  - Dashboard hides raw user IDs and org slugs behind dev affordances.
  - Workspace overview hides raw workspace UUID and provides Studio CTA.
  - Left-navigator footer renders unified "DiagramHQ" branding.
