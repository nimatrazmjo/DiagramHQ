# Pull Request: F105 — Immutable Audit Logs

## Summary
Implements cryptographically chained, append-only immutable audit logging recording who/what/when across all enterprise operations, including first-class auditing of AI-agent actions.

## Changes
- **Domain (`@diagramhq/domain`)**:
  - `packages/domain/src/ids.ts`: Added `'aud'` ID prefix and `AuditLogEntryId` branded type.
  - `packages/domain/src/audit-log.ts`:
    - Full who/what/when recording (`AuditEntry`): actor type (`human_user`, `ai_agent`, `scim_sync`, `api_key`, `system`), category, action name, status (`SUCCESS`, `FAILURE`, `DENIED`), target resource, details payload, timestamps, sequence indexing.
    - AI-Agent auditing: tracks AI model (e.g. `gemini-1.5-pro`), prompt summary, confidence score, and tool calls executed.
    - Cryptographic hash chaining (`computeAuditEntryHash`): multi-pass avalanche hash linking each record to `previousHash`, establishing a tamper-evident Merkle hash chain.
    - Append-only semantics (`appendAuditEntry`): monotonic sequence index, chronological monotonicity checks, immutable array freezing.
    - Integrity verification (`verifyAuditLogIntegrity`): recomputes hash signatures for every block, detecting payload tampering, backdated entries, severed chains, or dropped records.
    - Querying and filtering (`queryAuditLogs`): supports filtering by actor, actorType (e.g. `ai_agent`), category, status, resourceId, and time windows with pagination.
    - Exporting: `exportAuditLogToJson` and `exportAuditLogToCsv` for enterprise SIEM ingestion (Splunk, Datadog, AWS CloudWatch).
    - Lifecycle simulation harness: `simulateAuditLogLifecycle`.
  - `packages/domain/src/audit-log.test.ts`: 9 unit tests covering genesis initialization, append-only monotonicity, AI-agent auditing, tamper detection, hash chain integrity, filtering, and SIEM export.
  - `packages/domain/src/index.ts`: Exported `audit-log` module.
- **Web App (`@diagramhq/web`)**:
  - `apps/web/components/enterprise/audit-logs-modal.tsx`: Interactive Enterprise Immutable Audit Logs modal with KPI summary counters, search & category filters, dedicated AI-Agent Actions tab with model details and confidence badges, Cryptographic Chain Integrity verifier, and SIEM JSON/CSV export buttons.
  - `apps/web/components/enterprise/index.ts`: Exported `AuditLogsModal`.
  - `apps/web/audit-logs.spec.tsx`: 3 integration and component tests verifying UI rendering, AI-agent action recording, append-only immutability, and SIEM export formats.
