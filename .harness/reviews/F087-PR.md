# F087 — Dependency Analysis — Pull Request

## Summary

Implements the Architecture Dependency Graph and Path Analysis Engine for DiagramHQ (Phase 11 — Drift and Governance).

## Changes

### Domain (`packages/domain/src/`)

**`dependency-graph.ts`** (458 lines):
- `inferDependencyCategory(conn, src, tgt)` — classifies a connection as `runtime` / `compile-time` / `data` / `external`
- `detectDependencyCycles(nodes, connections)` — DFS back-edge cycle detection, returns `DependencyCycle[]`
- `findDependencyPaths(model, sourceId, targetId, maxHops)` — enumerates all paths, sorted by hop count
- `analyzeArchitectureDependencies(model, filters?)` — main API: builds `DependencyGraphReport` with direct edges, indirect edges, cycle list, metrics, and filtered edge set

**`dependency-graph.test.ts`** (396 lines): 3 unit tests
- ✓ Detects cyclic dependencies across services (A→B→C→A)
- ✓ Discovers indirect and transitive dependency paths (A→B→C→D)
- ✓ Filters graph by direct, indirect, runtime, compile-time, data, and external categories

**`index.ts`**: Exports `./dependency-graph`

### Web (`apps/web/`)

**`components/canvas/dependency-panel.tsx`** (563 lines): `<DependencyAnalysisModal />`
- 8 KPI metric cards (Nodes, Direct, Indirect, Runtime, Compile-time, Data, External, Cycles)
- Red cycle warning alert banner (shown when `metrics.hasCycles`)
- Type filter buttons (All / Direct / Indirect)
- Category filter dropdown (All / Runtime / Compile-time / Data / External)
- Node-focus select (scope edges to a single node)
- Search input (filter by source/target name or category)
- Edge card list with source→target clickable names, hop count, category + type badges
- Footer: filtered vs total edge count

**`components/canvas/index.ts`**: Exports `dependency-panel`

**`dependency.spec.tsx`** (248 lines): 3 integration tests

- ✓ Renders null when `isOpen=false`
