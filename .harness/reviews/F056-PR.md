# PR: F056 — Architecture snapshots

## Feature Summary
Implemented complete 6-dimension architecture snapshot capture, deep freezing, restoration, and diffing engine. Captures all core architecture aspects: objects, connections, views, flows (with steps), metadata, and documentation (markdown pages). Implements `captureFullArchitectureSnapshot`, `restoreFullArchitectureSnapshot`, and `diffArchitectureStates`. Added UI components `<SnapshotDetailsModal />` and `<SnapshotDiffModal />`.

## Acceptance Criteria Verified
- [x] Capture all 6 architecture dimensions (objects, connections, views, flows, metadata, documentation).
- [x] Immutable snapshots with deep freeze.
- [x] Acceptance Test: a snapshot restores to the captured state (`restoreFullArchitectureSnapshot`).
- [x] Full dimensional state diffing (`diffArchitectureStates` computing added, modified, removed across all dimensions).
- [x] UI components `<SnapshotDetailsModal />` (with dimension metric badges and restore trigger) and `<SnapshotDiffModal />` (with comparison counts).
