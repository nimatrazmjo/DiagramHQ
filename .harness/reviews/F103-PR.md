# Pull Request: F103 — SCIM Provisioning and Deprovisioning

## Summary
Implements RFC 7643 and RFC 7644 compliant SCIM 2.0 provisioning, attribute update, and deprovisioning lifecycle management for DiagramHQ Enterprise.

## Changes
- **Domain (`@diagramhq/domain`)**:
  - `packages/domain/src/ids.ts`: Added `'scim'` ID prefix and `ScimConfigId` branded type.
  - `packages/domain/src/scim.ts`:
    - SCIM 2.0 schemas (`urn:ietf:params:scim:schemas:core:2.0:User`, `Group`, `ServiceProviderConfig`, `PatchOp`, `Error`, `ListResponse`).
    - Core operations: `createScimUser`, `getScimUser`, `listScimUsers` (with filtering and pagination), `updateScimUser` (PUT), `patchScimUser` (RFC 7644 PATCH handling `active: false` deprovisioning), `deleteScimUser`, `createScimGroup`, `getScimGroup`, `listScimGroups`.
    - `getScimServiceProviderConfig` endpoint metadata generator.
    - Zero-network deterministic simulation harness `simulateScimProvisioningLifecycle`.
    - SCIM Bearer token generation and header validation.
  - `packages/domain/src/scim.test.ts`: 18 comprehensive unit tests covering provisioning, uniqueness enforcement, filtering, PUT, PATCH deactivation/reactivation, group management, and lifecycle simulation.
- **Web App (`@diagramhq/web`)**:
  - `apps/web/lib/scim-server.ts`: In-memory SCIM state singleton and seeding for web layer.
  - `apps/web/app/api/scim/v2/ServiceProviderConfig/route.ts`: RFC 7643 metadata discovery endpoint.
  - `apps/web/app/api/scim/v2/Users/route.ts`: RFC 7644 user list (GET) and provision (POST) endpoints with Bearer authentication.
  - `apps/web/app/api/scim/v2/Users/[id]/route.ts`: RFC 7644 individual user GET, PUT, PATCH (deprovisioning), and DELETE.
  - `apps/web/components/enterprise/sso-settings-modal.tsx`: Added SCIM 2.0 Provisioning tab with base URL copy, token generation, user directory, status badges, and 1-click end-to-end lifecycle verification test.
  - `apps/web/scim.spec.tsx`: 4 integration and component tests verifying UI rendering and REST API lifecycle execution.
