# F145 — Real views: reuse objects across views

## Summary

Delivered one-object-many-views Architecture OS capabilities for DiagramHQ (Phase 14 — UX Remediation):
- Create and switch views; each view stores object membership + layout positions, never duplicate objects.
- Add an existing model object to another view in ≤ 2 interactions (implemented as 1 click: `+ Add` button in Model Catalog).
- Removing an object from a view keeps it in the model (`removeObjectFromView ≠ deleteObject`).
- Editing a model object's name or metadata once reflects across all projecting views while per-view layout positions remain independent.
- Per-view layout persists independently via `/views/:viewId/objects/positions`.

## Changes

1. **Architecture Model Client** (`apps/web/lib/model/architecture-model-client.ts`):
   - Added `projectToView(viewObjects)` which projects only view member objects with their per-view layout positions and member connections.
   - Added real views client API methods: `fetchViews`, `createView`, `deleteView`, `fetchViewObjects`, `addObjectToView`, `removeObjectFromView`, `saveViewPositions`.

2. **Model Proxy & Server Handlers** (`apps/web/lib/model/model-proxy.ts`):
   - Added API endpoints and in-memory mock handlers:
     - `GET /architectures/:id/views` (lists all architecture views)
     - `POST /architectures/:id/views` (creates a view)
     - `GET /views/:viewId` and `PATCH /views/:viewId`
     - `DELETE /views/:viewId` (deletes view and associated view objects)
     - `GET /views/:viewId/objects` (lists view members with per-view positions)
     - `POST /views/:viewId/objects` (adds model object to view with position)
     - `DELETE /views/:viewId/objects/:objectId` (removes object from view without deleting it from model)
     - `PATCH /views/:viewId/objects/positions` (updates per-view layout coordinates)
     - `GET /views/:viewId/projection` (projects view members and positions)

3. **IcePanel Sidebar** (`apps/web/components/canvas/icepanel-sidebar.tsx`):
   - Added Architecture Views section in Diagrams tab with active indicator, 1-click view switching, delete confirmation, and inline create view form (`name`, `kind`, `level`).
   - Added 1-click addition button (`data-testid="add-to-view-${item.id}"` / `+ Add`) in Model Catalog for any model object not currently in the active view.
   - Added "In View ✓" badge and remove button (`data-testid="remove-from-view-${item.id}"`) for objects already in the view.

4. **DiagramHQ Studio** (`apps/web/app/studio/page.tsx`):
   - Added real views state: `views`, `activeViewId`, `effectiveViewId`, and `allModelObjects`.
   - Added header view switcher dropdown (`studio-view-switcher`) for switching views.
   - Added `handleSelectView`, `handleCreateView`, `handleDeleteView`, `handleAddObjectToActiveView`, `handleRemoveObjectFromActiveView`.
   - Synchronized `allModelObjects` so renaming or updating an object once reflects across all projecting views while preserving independent per-view layouts.

5. **Test Suite** (`apps/web/real-views-reuse.spec.tsx`):
   - 6 automated unit & integration tests covering view creation & listing, independent per-view layout coordinates, single-point editing reflecting across multiple views, remove-from-view invariance (`remove ≠ delete`), `projectToView` layout projection, and IcePanelSidebar 1-click addition/removal UI affordances.
