# PR: F009 — Infinite Canvas

## Summary
- Defines framework-agnostic canvas interfaces (`CanvasRenderer<TContainer>`, `CanvasNode`, `CanvasEdge`, `CanvasViewport`, `CanvasInteractionHandler`) in `packages/domain/src/canvas.ts` per ADR-0002.
- Implements pure model projection `projectViewModelToCanvas` mapping objects/connections into canvas coordinates.
- Implements transient Zustand store in `apps/web/lib/canvas-store.ts` strictly isolated from domain entity data (Layer Boundaries Rule 4).
- Implements `ReactFlowCanvasRenderer` and `InfiniteCanvas` component with custom semantic architectural nodes (`SystemNode`, `AppNode`, `StoreNode`), MiniMap, Controls, and background grid.
- Mounts interactive canvas into `/workspace/[workspaceId]` studio overview.
- Adds 28 automated tests (11 domain, 17 web) for a monorepo total of 225 passing tests.
