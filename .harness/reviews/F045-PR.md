# F045 — User journeys

## Description
This PR implements F045 — User journeys (Phase 05 — Flows).

Supports user-journey flow type, persona step context, and sequence playback:
- Extends domain types with `FlowType` (`'sequence' | 'user_journey' | 'data_flow' | 'api_flow'`), actor linking (`actorId`, `persona`), and step-level journey attribution (`actorAction`, `userIntent`).
- Implements `createUserJourneyFlow()` with actor object existence checks, step connection validation, and normalized step indexing.
- Implements `annotateUserJourneyStep()` allowing updates to notes, persona action, and user intent without altering step order.
- Provides `getUserJourneyPlaybackStepInfo()` extracting structured journey context during interactive step-by-step playback.
- Updates canvas flow projection (`projectFlowToCanvas`) to pass persona, action, and intent into `flowMetadata` and active edge data.
- Adds user journey context banner to `<FlowPlaybackToolbar />` and adds `<UserJourneyOverlay />` canvas component.

### Changes

**Domain layer (`packages/domain/src/`)**
- `types.ts`: Added `FlowType`, updated `Flow` with `type`, `actorId`, `persona`, and updated `FlowStep` with `actorAction`, `userIntent`.
- `flow.ts`: Updated `createFlow`, `updateFlow`, and `addFlowStep` to handle `type`, `actorId`, `persona`, `actorAction`, `userIntent`; implemented `createUserJourneyFlow` and `annotateUserJourneyStep`.
- `flow-playback.ts`: Added `flowType` to `FlowPlaybackState`, implemented `getUserJourneyPlaybackStepInfo`.
- `flow-view.ts`: Enhanced `FlowEdgeData` and `flowMetadata` to propagate user journey persona and active step intent.
- `user-journeys.test.ts`: Added 5 unit tests verifying user journey flow creation, actor validation, step annotation, playback state inspection, and canvas projection.

**Web layer (`apps/web/`)**
- `components/canvas/flow-playback-toolbar.tsx`: Updated to accept optional `persona`, `actorAction`, and `userIntent` and render user journey context chips.
- `components/canvas/user-journey-overlay.tsx`: Created `<UserJourneyOverlay />` component rendering journey title, persona badge, progress bar, current step action, user intent, and note.
- `components/canvas/index.ts`: Exported `UserJourneyOverlay`.
- `user-journeys.spec.tsx`: Added 4 integration tests verifying user journey instantiation, step-by-step playback, canvas projection, and UI rendering.
