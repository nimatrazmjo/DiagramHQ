## Description
Implements **F026 — Database** from Phase 03 (Architecture Model): Database element CRUD, rendering, parent application linkage (`parentId`), database kinds (PostgreSQL, MySQL, MongoDB, Redis, Elasticsearch, DynamoDB, SQLite, Cassandra, Store), technology tagging, schema and version metadata, and canvas projection.

- **Domain Layer (`packages/domain`)**:
  - `DatabaseKind`: 'postgresql' | 'mysql' | 'mongodb' | 'redis' | 'elasticsearch' | 'dynamodb' | 'sqlite' | 'cassandra' | 'store'.
  - `DatabaseMetadata` interface: `databaseKind`, `technology`, `schema`, `version`, `host`, `replication`, `c4Level`, `c4Kind`.
  - `DatabaseNodeData` interface: `label`, `databaseKind`, `technology`, `schema`, `version`, `description`, `parentId`, `databaseId`.
  - Helpers: `createDatabase` (`kind: 'store'`, `sto_` ID prefix), `isDatabase`.
  - Canvas projection: `projectDatabaseToCanvas` mapping database objects to React Flow canvas nodes with 220x130 dimensions, technology badges, schema tags, and theme-based styling.
  - 4 unit tests in `packages/domain/src/database.test.ts`.
- **API Layer (`apps/api`)**:
  - 6 comprehensive E2E tests in `apps/api/src/architectures/database.e2e.spec.ts` covering:
    - Database creation under a parent application (`parentId: applicationId`).
    - Standalone Redis cache creation without parent (`parentId: null`).
    - Data connection between Application and Database (`sourceObjectId: app, targetObjectId: db`).
    - Updating Database metadata via `PATCH /objects/:id`.
    - Architecture model snapshot reload verification (`/architectures/:id/model`).
    - Deletion of Database with cascading connection removal.
- **Web Client Layer (`apps/web`)**:
  - `DatabaseNode` component (`apps/web/components/canvas/database-node.tsx`) rendering:
    - Cylinder database icon with theme gradient styling for PostgreSQL, MySQL, MongoDB, Redis, Elasticsearch, DynamoDB.
    - Kind badge (`[Database: PostgreSQL]`, `[Database: Redis]`, etc.) with `data-testid="database-kind-badge"`.
    - Technology tag (`[...]`) with `data-testid="database-technology"`.
    - Schema badge with `data-testid="database-schema"`.
    - 4-way connection handles on all 4 directions.
  - Registration in `apps/web/components/canvas/custom-nodes.tsx` for `database`.
  - 5 tests in `apps/web/database.spec.ts` covering node rendering, variant styling, selection ring, and canvas projection.
