## Description
Implements **F016 — Undo/redo** from Phase 02 (Canvas): a reversible command layer supporting per-session history on the canvas, synchronization with React Flow nodes/edges state, keyboard shortcuts, and toolbar controls.

- **Reversible Command Infrastructure**:
  - `Command<T>` interface extended with optional `applyCanvasUpdate(setNodes, setEdges, mode: 'execute' | 'undo')` using `@xyflow/react` types.
  - `CommandDispatcher` enhanced with `canUndo()`, `canRedo()`, `peekUndo()`, `peekRedo()`, `subscribe()`, `notify()`, and `getUndone()` for reactive UI binding.
- **Reversible Commands**:
  - `CreateNodeCommand`: adds node on execute, removes node on undo.
  - `DeleteNodeCommand`: removes node & connected edges on execute, restores them on undo.
  - `ConnectNodesCommand`: adds edge on execute, removes edge on undo.
  - `UpdateNodeMetadataCommand`: updates node metadata on execute, restores prior data on undo.
  - `MoveNodeCommand`, `MoveNodesCommand`, `AlignNodesCommand`, `ApplyLayoutCommand`: updated with `applyCanvasUpdate` for undo/redo position syncing.
- **Canvas UI & Keyboard Integration**:
  - `infinite-canvas.tsx`: subscribes to dispatcher state for real-time button enabled/disabled states.
  - Keyboard shortcuts: <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>Z</kbd> (undo) and <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd> (redo), suppressed when focused in text inputs.
  - Toolbar buttons: Undo (↶, `data-testid="undo-btn"`) and Redo (↷, `data-testid="redo-btn"`).
- **Per-Session State**: Command history is in-memory UI state, cleanly separated from persisted domain backend state according to Layer Boundary Rules 3 & 4.
