# F096 — Export — Pull Request

## Summary
Implements multi-format architecture diagram and view export engine supporting SVG, PNG, PDF, and JSON with configurable scale (1x, 2x, 3x, 4x), background themes (dark, light, transparent), metadata banners, component legends, and checksum validation (Phase 12 — Documentation).

## Changes

### Domain (`packages/domain/src/`)
- **`export.ts`**: Pure architecture export engine:
  - **Types & Options**:
    - `ExportFormat`: `'svg' | 'png' | 'pdf' | 'json'`.
    - `ExportTheme`: `'dark' | 'light' | 'transparent'`.
    - `ExportScale`: `1 | 2 | 3 | 4`.
    - `ExportOptions`: format, scale, theme, padding, customTitle, includeMetadata, includeLegend.
    - `ExportResult`: format, mimeType, filename, content, byteSize, dimensions (width, height, scale), dataUri, checksum.
  - **Filename & Checksum Utilities**:
    - `sanitizeFilename(name)`: Produces clean slug for filenames.
    - `generateExportFilename(viewName, format, options)`: Formats standard names with timestamp (e.g. `titanium-financial-core-system-context-20261003.svg`).
    - `computeContentChecksum(content)`: Deterministic 32-bit FNV-1a checksum for content integrity.
  - **Bounding Box Calculation**:
    - `calculateExportBoundingBox(nodes, options)`: Computes bounds with padding, header offset, and legend spacing.
  - **SVG Vector Rendering Engine (`renderViewToSvg`)**:
    - Generates self-contained, valid XML/SVG with theme palettes (dark, light, transparent).
    - Responsive `viewBox` and scaled pixel dimensions.
    - Embedded typography, CSS classes, drop shadow filters, and arrow markers (`marker-arrow-sync`, `marker-arrow-async`).
    - Title banner with architecture name and timestamp (when `includeMetadata: true`).
    - Crisp C4 node shapes with kind badges (`system`, `application`, `store`, `component`, `actor`), titles, and technology tags.
    - Connection paths with kind-specific styling, dashed lines for async connections, and centered edge label badges.
    - Component kind legend swatches (when `includeLegend: true`).
  - **PDF Vector Engine (`renderViewToPdf`)**:
    - Produces valid PDF 1.4 document structure (`%PDF-1.4 ... %%EOF`).
    - Document Catalog, Page tree, A4 Landscape media box (842 × 595 pt), Info dictionary, and vector drawing operators.
    - Embedded SVG vector stream.
  - **JSON Snapshot Engine (`exportViewAsJson`)**:
    - Emits structured JSON (`ViewExportJsonPayload`) with architecture ID/name, view definition, placed objects with coordinates and dimensions, and connections.
  - **Unified Exporter**:
    - `exportArchitectureView(view, model, options, viewObjects)`: Universal entrypoint returning `ExportResult`.
    - `exportMultipleViews(views, model, options, viewObjectsMap)`: Batch view export utility.
- **`export.test.ts`**: 15 unit tests covering filename sanitization, timestamped filenames, checksum calculation, bounding box geometry, SVG rendering (elements, themes, scales), PDF 1.4 generation, JSON snapshot serialization, unified exporter dispatches, and batch multi-view exports.
- **`index.ts`**: Exported `export`.

### Web (`apps/web/`)
- **`components/canvas/export-modal.tsx`**: `<ExportModal />` canvas UI:
  - Format selector tab bar: `PNG (Raster Image)`, `SVG (Vector)`, `PDF (Print Document)`, `JSON (Model Data)`.
  - View switcher dropdown when multiple views are available.
  - Live interactive preview container displaying rendered SVG, formatted JSON, or PDF document card.
  - Preview status pill displaying live dimensions, file size, and scale multiplier.
  - Settings sidebar:
    - Custom title override input.
    - Resolution / Scale selector grid (1x, 2x, 3x, 4x).
    - Canvas background theme selector (Dark, Light, Transparent).
    - Toggles for Title & Metadata Banner and Component Legend.
  - Bottom action bar with filename display, "Copy to Clipboard", and "Download [FORMAT]".
- **`components/canvas/index.ts`**: Exported `export-modal`.
- **`export.spec.tsx`**: 3 integration tests verifying closed modal, export modal rendering with controls and actions, and live diagram preview pane containing nodes and connections.
