## Description
Implements **F031 — Object lifecycle** from Phase 03 (Architecture Model): Lifecycle states (`future` -> `live` -> `deprecated` -> `removed`), transition rules and validation, transition audit recording, and model persistence.

- **Domain Layer (`packages/domain`)**:
  - `LifecycleState`: `'future' | 'live' | 'deprecated' | 'removed'`.
  - `LifecycleTransition` interface: `from`, `to`, `at`, `by`, `reason`.
  - `isValidLifecycleTransition(from, to)` enforcing state machine rules:
    - `future` -> `live`
    - `live` -> `deprecated`, `removed`
    - `deprecated` -> `removed`
    - `removed` has no outgoing transitions
  - `createLifecycleTransition`: transition factory with validation error throwing.
  - `getLifecycleBadgeColor`: returns semantic badge styling classes for each lifecycle state.
  - `LIFECYCLE_STATES`: array of valid lifecycle states.
  - Unit tests in `packages/domain/src/lifecycle.test.ts`.
- **API Layer (`apps/api`)**:
  - Integration tests in `apps/api/src/architectures/lifecycle.e2e.spec.ts`:
    - Setting lifecycle state (`future`) on model objects via `PATCH /objects/:id`.
    - Recording lifecycle transition (`future` -> `live`) with timestamp in `metadata.lifecycleTransitions`.
    - Reloading object via `GET /objects/:id` and confirming state persistence.
    - Snapshot reload via `GET /architectures/:id/model` verifying lifecycle metadata.
- **Web Layer (`apps/web`)**:
  - Unit tests in `apps/web/lifecycle.spec.ts` verifying domain lifecycle functions within the web package context.
