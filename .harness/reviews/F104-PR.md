# Pull Request: F104 — Advanced RBAC

## Summary
Implements enterprise-grade fine-grained roles beyond the base catalog with strict principle of least privilege enforcement, custom role authoring, least privilege evaluation with explicit denials, and automated privilege risk auditing.

## Changes
- **Domain (`@diagramhq/domain`)**:
  - `packages/domain/src/ids.ts`: Added `'role'` ID prefix and `CustomRoleId` branded type.
  - `packages/domain/src/advanced-rbac.ts`:
    - Fine-grained permission catalog across 7 enterprise domains (`architecture`, `model`, `flow`, `docs`, `governance`, `admin`, `billing`).
    - Built-in specialized enterprise roles:
      - `Security Auditor`: Allowed read-only views, audit logs, compliance reports, and security scans; explicitly denied from mutating models, editing diagrams, or managing workspace.
      - `Documentation Specialist`: Allowed markdown authoring, publishing, and diagram view; explicitly denied from mutating core architectural objects.
      - `Compliance Officer`: Allowed audit inspection, framework mapping, and ADR approval; explicitly denied from altering diagrams or deleting objects.
      - `Junior Architect`: Allowed drafting diagrams and flows; explicitly denied from publishing, deleting models, or managing org admin.
      - `Billing Administrator`: Allowed managing subscriptions, seats, and invoicing; strictly isolated with zero access to proprietary architecture diagrams or models.
    - Custom role creation with dynamic allow and deny lists.
    - Least privilege evaluation engine (`evaluateFineGrainedPermission`, `assertFineGrainedPermission`): explicit deny overrides allow; ungranted permissions denied by default.
    - Out-of-scope action denial test harness: `testFineGrainedRoleDenial`.
    - Least privilege audit engine (`auditRoleLeastPrivilege`): computes privilege risk score (LOW/MEDIUM/HIGH/CRITICAL), flags destructive capabilities, and provides actionable remediation recommendations.
  - `packages/domain/src/advanced-rbac.test.ts`: 13 comprehensive unit tests covering permission catalog, specialized roles, custom role authoring, evaluation decisions, out-of-scope denial verification, and risk auditing.
  - `packages/domain/src/index.ts`: Exported `advanced-rbac` module.
- **Web App (`@diagramhq/web`)**:
  - `apps/web/components/enterprise/advanced-rbac-modal.tsx`: Comprehensive Advanced RBAC management modal featuring Roles Catalog, Real-Time Least Privilege Evaluator with instant decision badges, Risk & Compliance Audit dashboard, and Custom Role Authoring form.
  - `apps/web/components/enterprise/index.ts`: Exported `AdvancedRbacModal`.
  - `apps/web/advanced-rbac.spec.tsx`: 5 integration and component tests verifying UI rendering and least privilege out-of-scope action denial.
