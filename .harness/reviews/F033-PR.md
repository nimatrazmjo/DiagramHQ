## Description
Implements **F033 — Container diagrams** from Phase 04 (Diagrams and Views): Container diagram type (Level 2 saved view), rendering applications, stores, and queues from the underlying model with layout coordinates, position updating, and model entity retention upon diagram deletion.

- **Domain Layer (`packages/domain`)**:
  - `createContainerViewOptions`: helper for creating Level 2 container view options.
  - `isContainerView`: predicate for container diagram detection.
  - `getViewLevelLabel`: returns `Level 2 — Container`.
  - Unit tests in `packages/domain/src/view.test.ts`.
- **API Layer (`apps/api`)**:
  - `apps/api/src/views/container-diagram.e2e.spec.ts`: 4 E2E integration tests:
    - Create container diagram (kind: container) as a saved view.
    - Render application containers, database stores, and queues from the model with layout coordinates.
    - Update container diagram object coordinates via `PATCH /views/:id/objects/:objectId/position`.
    - Delete container diagram view and verify all model entities remain intact in the architecture model.
- **Web Layer (`apps/web`)**:
  - Tests in `apps/web/container-diagram.spec.ts` verifying domain container view helpers.
