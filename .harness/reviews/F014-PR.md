## Description
Implements **F014 — Alignment** from Phase 02 (Canvas):
- **Snap to grid**: `snapToGrid(position, gridSize = 20)` in the domain layer; wired into single-node and group drag-stop paths behind a toolbar toggle.
- **Align selected nodes**: left, right, top, bottom, center-horizontal, center-vertical — pure `alignNodes(nodes, axis)`.
- **Distribute selected nodes**: horizontal / vertical even-gap spacing — pure `distributeNodes(nodes, axis)`, no-op below 3 nodes.
- **Alignment toolbar**: bottom-center panel shown when `selectedNodeIds.length > 1` — 6 align buttons, 2 distribute buttons (disabled below 3 selected), snap-to-grid toggle.
- **Command layer**: `AlignNodesCommand` implements `Command<AlignedNodeResult[]>`, mirrors `MoveNodesCommand`'s batch-persist contract, captures prev positions for `undo()`.
