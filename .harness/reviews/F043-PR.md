# F043 — Flow visualization

## Description
This PR implements F043 — Flow visualization (Phase 05 — Flows).

Renders the sequence flow over the architecture model:
- Highlights the flow path over the existing architecture.
- Projects flow steps onto canvas nodes and edges via `projectFlowToCanvas`.
- Adds flow step badges (`#1`, `#2`...), sequential notes, and animated active pulses to edges and nodes.
- Dims non-participating elements so the flow sequence visually pops out over the architecture.
- Supports active step playback indexing (`activeStepIndex`) for step scrubber and playback highlighting.

### Changes

**Domain layer (`packages/domain/src/`)**
- Added `flow-view.ts`:
  - `projectFlowToCanvas(objects, connections, flow, viewObjects?, options?)` — pure projection function mapping model and flow sequence onto canvas nodes and edges.
  - Generates `flowMetadata` (flow ID, name, step count, participating object IDs).
  - Annotates nodes with `isInFlow`, `flowStepNumbers`, `highlighted`, and `isDimmed`.
  - Annotates edges with `isInFlow`, sequential `flowStepNumber`, notes, label formatting, `animated: true`, and `isDimmed: false`.
  - Supports `options.activeStepIndex` highlighting specific active step edges and endpoint participants for playback.
- Added 4 unit tests in `packages/domain/src/flow-view.test.ts`.
- Exported `flow-view` from `packages/domain/src/index.ts`.

**Web layer (`apps/web/`)**
- Added `apps/web/components/canvas/flow-badges.tsx` (`FlowBadges` component with step pills, pulse animation, and SVGs).
- Integrated `FlowBadges` and flow visual states (active ring/dimmed opacity) across node types:
  - `app-node.tsx`
  - `system-node.tsx` (both internal and external boundaries)
  - `database-node.tsx`
  - `component-node.tsx`
  - `queue-node.tsx`
  - `person-node.tsx`
- Enhanced `apps/web/components/canvas/icepanel-edge.tsx` to handle flow stroke color, width, glowing filter, and `#flowStepNumber` pill badges.
- Exported `FlowBadges` in `apps/web/components/canvas/index.ts`.
- Added integration suite in `apps/web/flow-visualization.spec.ts` (4 tests).
