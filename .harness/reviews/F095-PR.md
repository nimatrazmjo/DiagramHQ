# F095 — Architecture Portal — Pull Request

## Summary
Implements an interactive, public read-only architecture explorer allowing anonymous visitors to navigate, search, zoom, and drill down across C4 levels (Context, Container, Component), execution flows, ADRs, and dependencies without requiring an account (Phase 12 — Documentation).

## Changes

### Domain (`packages/domain/src/`)
- **`ids.ts`**: Added `'ptl'` prefix to `IdPrefix` and exported `type PortalId = Id<'ptl'>`.
- **`architecture-portal.ts`**: Pure architecture portal engine:
  - **C4 Multi-Level Projections (`buildPortalLevelProjection`)**:
    - Context Level (L1): Visualizes high-level systems, boundary actors, and cross-system integrations.
    - Container Level (L2): Filters and projects applications and data stores contained within a parent system.
    - Component Level (L3): Projects modular services, controllers, and packages within a container.
    - Generates dynamic breadcrumb hierarchy path (`breadcrumbs`) with click-to-ascend level tracking.
  - **Camera & Viewport Controls**:
    - `zoomPortalCamera(camera, zoomDelta, minZoom, maxZoom)`: Smooth zoom bounded [0.2x, 3.0x].
    - `panPortalCamera(camera, deltaX, deltaY)`: Fluid translation.
    - `fitPortalCameraToNodes(nodes, viewportWidth, viewportHeight)`: Bounds-fitting auto-zoom and center alignment.
  - **Inspector & Dependency Highlighting**:
    - `inspectPortalObject(model, objectId)`: Extracts technology, owner, SLA, contained subcomponents, inbound callers, outbound dependencies, associated ADRs, and flows.
    - `getDependencyHighlighting(model, objectId)`: Calculates upstream/downstream dependency subgraphs and active connection IDs.
  - **Execution Flow Playback**:
    - `initPortalFlowPlayback(flow, steps, connections)`: Initializes step-by-step interactive walkthrough.
    - `stepPortalFlowPlayback(playback, targetStepIndex, steps, connections)`: Traverses flow steps, identifying participating source/target nodes and active edges.
  - **Global Architecture Search (`searchArchitecturePortal`)**:
    - Multi-entity scoring across objects, views, flows, ADRs, and documentation.
- **`architecture-portal.test.ts`**: 13 unit tests covering initialization, C4 projections (Context, Container, Component), drill-down, upward navigation, camera zoom/pan/fit, inspector extraction, dependency highlighting, flow playback stepping, and multi-entity search scoring.
- **`index.ts`**: Exported `architecture-portal`.

### Web (`apps/web/`)
- **`components/canvas/architecture-portal-panel.tsx`**: `<ArchitecturePortalModal />` interactive explorer:
  - Top header with public badge: `"PUBLIC EXPLORER • NO ACCOUNT REQUIRED"`.
  - Global multi-entity search bar with popover and keyboard navigation.
  - C4 Breadcrumb navigation bar with current level badge (`CONTEXT (L1)`, `CONTAINER (L2)`, `COMPONENT (L3)`) and drill-up button.
  - Canvas viewport with zoom in/out, reset, and fit-to-view controls.
  - Interactive C4 node cards displaying kind, status, technology, inbound/outbound connection counts, and "Drill Down →" action.
  - Side drawer with dual modes:
    - Object Inspector: Displays detailed properties, SLA, contained components, upstream callers, downstream dependencies, and associated ADRs.
    - Execution Flow Playback: Step progression bar, step description, active participants, and Previous/Next navigation.
- **`components/canvas/index.ts`**: Exported `architecture-portal-panel`.
- **`architecture-portal.spec.tsx`**: 5 integration tests verifying closed state, public read-only header/banner, C4 level breadcrumbs and node cards, container level drill-down with inspector, and global search/flow selector.
