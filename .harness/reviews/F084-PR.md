# Pull Request: F084 — Architecture drift

## Description
Architecture drift detection and governance engine for DiagramHQ (Phase 11 — Drift & Governance):
- Documented vs Actual State Comparison:
  - Compares documented architecture model (objects and connections) against imported/discovered actual state (from cloud discovery, git scan, Kubernetes manifests, Terraform).
  - Surfaces the full delta: unmanaged resources, missing resources, attribute mismatches, undocumented connections, and missing connections.
  - Computes complete delta summaries with severity breakdowns (`critical`, `high`, `medium`, `low`, `informational`).
- 3 Canonical Action Workflows:
  - **Action 1: Update Model (`reconcileDriftDirectly`)**: Reconciles selected or all drift items directly into the documented architecture model without destructive side effects, adding unmanaged resources/connections, removing missing entities, and syncing attribute mismatches.
  - **Action 2: Ignore (`ignoreDriftItem`)**: Suppresses specific drift items with an audit-logged justification reason and timestamp, preserving compliance tracking.
  - **Action 3: Create Change Request (`createChangeRequestFromDrift`)**: Generates an `ArchitecturePullRequest` with visual diff (`computeVisualArchitectureDiff`), structured change set (`computeArchitectureChangeSet`), risk analysis, and affected systems list.
- Grounded Evidence & Traceability:
  - Preserves `DriftEvidence` (`sourceType`, `sourceRef`, `confidence`, `detectedAt`, `details`) on every drift item.
- Canvas UI Integration:
  - `<ArchitectureDriftModal />`: Full-featured interactive drift modal with KPI metric cards (Total Drift, Unmanaged, Missing, Mismatches), severity and type filters, selectable drift items, detailed attribute comparison table, expandable evidence drawer, and direct action triggers for Update Model, Ignore, and Create Change Request.
