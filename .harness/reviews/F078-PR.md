# Pull Request: F078 — AWS

## Description
AWS cloud infrastructure import and topology mapping engine for DiagramHQ (Phase 10 — Infrastructure Integrations). Enables engineering teams to import and map real AWS cloud architectures across accounts and regions directly into the DiagramHQ architecture model:
- Discovers and maps all 13 canonical AWS resource types:
  - Compute: `ec2` (Bastion/Instances), `ecs` (Clusters/Services), `eks` (Kubernetes clusters), `lambda` (Serverless functions)
  - Storage & Databases: `rds` (Relational databases), `dynamodb` (NoSQL tables), `s3` (Object storage buckets)
  - Networking & Edge: `cloudfront` (Global CDN ingress), `api_gateway` (REST/HTTP APIs), `vpc` (Virtual Private Clouds)
  - Messaging & Integration: `sqs` (Message queues), `sns` (Pub/sub topics), `eventbridge` (Enterprise event buses)
- Maps AWS resources into typed `ModelObject` records with:
  - `kind`: `'group'` for VPCs, `'store'` for databases & storage, `'application'` for compute & gateways, `'component'` for messaging
  - Standardized metadata: ARNs, resource IDs, AWS account ID, primary region, VPC IDs, subnet IDs, and user tags
  - Hierarchical containment: resources provisioned in a VPC have `parentId` anchored to the VPC group object when VPC containment is enabled.
- Inter-resource connection inference:
  - Detects and creates typed `ModelConnection` records between interdependent AWS services:
    - CloudFront -> S3 / API Gateway (HTTPS origin fetch)
    - API Gateway -> Lambda / ECS / EC2 (AWS_PROXY integration)
    - Lambda / ECS -> RDS (SQL queries), DynamoDB (API operations), S3 (Object storage)
    - Lambda / ECS -> SNS / EventBridge / SQS (asynchronous event publication)
    - SNS -> SQS (fanout subscription)
    - EventBridge -> SQS / Lambda (rule targets)
- Traceable cloud evidence: generates `AwsCloudEvidence` records (`sourceType: 'cloud_resource'`) with 100% confidence referencing raw ARNs, regions, and account IDs.
- Acceptance test verified: imported a mocked AWS account with all 13 required AWS resource types correctly mapped to model objects, connections, and evidence.
