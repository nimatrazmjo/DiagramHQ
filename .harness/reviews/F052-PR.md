# F052 — Share links

## Description
This PR implements F052 — Share links (Phase 06 — Collaboration).

Supports read-only share links preserving viewer position, zoom, and active selection without requiring an account:
- Pure domain engine in `packages/domain/src/share-links.ts`:
  - `ShareLinkCameraState`: `{ panX, panY, zoom }`.
  - `ShareLinkPayload`: immutable payload containing `id`, `workspaceId`, `viewId`, `camera`, `selectedObjectId`, `selectedConnectionId`, `permission: 'read_only'`, `allowComments`, `expiresAt`, `createdAt`.
  - `createShareLink()`: generates link payload with optional expiration and camera/selection preferences.
  - `encodeShareLinkToken()` / `decodeShareLinkToken()`: URL-safe Base64 token serialization with validation.
  - `verifyShareLink()`: validates token structure and enforces expiration.
  - `resolveAnonymousViewState()`: projects initial canvas view state for unauthenticated / anonymous users.
  - `generateShareLinkUrl()`: generates full sharing URL with token query parameter.
- ID prefix: Added `'shl'` and `ShareLinkId` to `packages/domain/src/ids.ts`.
- Web UI components in `apps/web/components/canvas/share-link-modal.tsx`:
  - `<ShareLinkModal />`: modal providing share link URL, quick copy button, checkboxes to preserve current camera and active selection, expiration dropdown (never, 24h, 7d, 30d), and read-only notice.
  - `<ReadOnlyBanner />`: canvas banner indicating read-only shared view, focused entity name, and reset camera action.
- Test coverage:
  - 6 unit tests in `packages/domain/src/share-links.test.ts`.
  - 4 integration tests in `apps/web/share-links.spec.tsx`.
