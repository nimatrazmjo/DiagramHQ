## Description
Implements **F021 — C4 Component** from Phase 03 (Architecture Model): C4 Level 3 component diagrams modeling architectural building blocks (controllers, services, repositories, middlewares) inside a container (`parentId = container.id`), with inter-component connections, technology badges, and Level 4 code mapping stubs (DEC-001 / ADR-0001).

- **Domain Layer (`packages/domain`)**:
  - `C4ComponentKind`: 'component' | 'controller' | 'service' | 'repository' | 'middleware' | 'handler'.
  - `C4CodeMappingStub` interface capturing repository URL, relative file path, symbol, and branch.
  - `C4ComponentNodeData` and `C4ContainerBoundaryNodeData` interface definitions.
  - Helpers: `createC4Component`, `createC4Controller`, `createC4DomainService`, `createC4Repository`.
  - Predicates: `isComponent`, `isComponentOfContainer`, `getContainerComponents`, `getC4ComponentKind`.
  - Canvas projection: `projectC4ComponentToCanvas` mapping container boundary and component nodes with L4 code stubs and edges.
  - 4 unit tests in `packages/domain/src/c4-component.test.ts`.
- **API Layer (`apps/api`)**:
  - Integration with existing `ArchitecturesService` and `ArchitecturesController`.
  - 7 comprehensive E2E tests in `apps/api/src/architectures/c4-component.e2e.spec.ts` verifying creation of components inside a container, L4 code mapping metadata persistence, sync connections, model snapshot reload identity, and cascade deletion.
- **Web Client Layer (`apps/web`)**:
  - `C4ComponentNode` component (`apps/web/components/canvas/c4-component-node.tsx`) rendering:
    - Specific visual themes for Controllers, Services, Repositories, and generic Components.
    - Technology tag `[Technology]`.
    - L4 Code mapping stub indicator with file path and inspect action `data-testid="c4-code-mapping-btn"`.
  - `C4ContainerBoundaryNode` component (`apps/web/components/canvas/c4-container-boundary-node.tsx`) rendering enclosing parent container boundary.
  - Registration in `apps/web/components/canvas/custom-nodes.tsx` for `c4Component`, `c4ContainerBoundary`, and `component`.
  - 7 tests in `apps/web/c4-component.spec.ts` covering SSR node rendering, L4 code stub inspect callback, container boundary rendering, canvas mounting, and ArchitectureModelClient reload identity.
