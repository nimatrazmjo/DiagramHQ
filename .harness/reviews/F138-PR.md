# Pull Request: F138 — Canvas Context Menus

## Overview

Implements F138 from `PHASE-14-UX-REMEDIATION.md`, introducing right-click contextual menus across the infinite canvas for nodes, edges, and the empty canvas pane, backed by undoable command dispatcher operations.

## Changes

### 1. Web Commands (`apps/web/lib/commands/`)
- **`delete-edge-command.ts`**: Implements undoable edge deletion via `applyCanvasUpdate(setNodes, setEdges, mode)`.
- **`reverse-edge-command.ts`**: Implements undoable edge reversal via `applyCanvasUpdate(setNodes, setEdges, mode)`.
- **`index.ts`**: Exported `DeleteEdgeCommand` and `ReverseEdgeCommand`.

### 2. Canvas Context Menu Component (`apps/web/components/canvas/`)
- **`context-menu.tsx`**: Reusable `CanvasContextMenu` component:
  - **Node Menu**: Rename, Duplicate (+40px offset via `CreateNodeCommand`), Delete (`DeleteNodeCommand`), Add Connection, Add to View, Drill in.
  - **Edge Menu**: Edit Label, Reverse Direction (`ReverseEdgeCommand`), Delete (`DeleteEdgeCommand`).
  - **Pane Menu**: Add Object submenu (App, System, Store, Component, Queue, Person, Group, etc.), Paste, Select All, Fit View, Auto-layout.
  - **Auto-clamping**: Ensures menus stay completely visible within viewport boundaries.
  - **Dismissal**: Closes automatically on `Escape`, outside click, or window scroll/resize.
- **`index.ts`**: Exported `CanvasContextMenu`.

### 3. Infinite Canvas Integration (`apps/web/components/canvas/infinite-canvas.tsx`)
- Connected `onNodeContextMenu`, `onEdgeContextMenu`, and `onPaneContextMenu` to ReactFlow.
- Handlers map menu actions to command dispatcher:
  - Node duplicate: creates clone with `(Copy)` label and offset via `CreateNodeCommand`.
  - Node delete: dispatches `DeleteNodeCommand`.
  - Edge reverse: dispatches `ReverseEdgeCommand`.
  - Edge delete: dispatches `DeleteEdgeCommand`.
  - Pane add node: dispatches `CreateNodeCommand` with canvas-projected coordinates.
- Canvas undo/redo state synchronization smoothly restores and reverts edge and node mutations.

### 4. Tests (`apps/web/context-menu.spec.tsx`)
- 8 tests covering:
  - Node context menu rendering and callback dispatch.
  - Edge context menu rendering and callback dispatch.
  - Pane context menu rendering and callback dispatch.
  - Undo and redo execution with `defaultCommandDispatcher` for:
    - Node creation
    - Node deletion
    - Edge reversal
    - Edge deletion
  - Canvas fit-view and auto-layout handlers.
