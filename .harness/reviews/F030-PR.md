## Description
Implements **F030 — Object metadata** from Phase 03 (Architecture Model): Full metadata schema for architecture model objects and interactive Web inspector panel for viewing and updating object metadata properties.

- **Domain Layer (`packages/domain`)**:
  - `ObjectMetadataSchema` interface covering identity, ownership, technical status/environment, classification tags/domains/links, risk & compliance, SLAs (SLA, RTO, RPO, cost center), documentation/repository, and lifecycle transitions.
  - Enumeration constants: `OBJECT_STATUS_OPTIONS`, `OBJECT_ENVIRONMENT_OPTIONS`, `OBJECT_CRITICALITY_OPTIONS`, `OBJECT_DATA_CLASSIFICATION_OPTIONS`.
  - Helpers: `mergeObjectMetadata`.
  - Unit tests in `packages/domain/src/object-metadata.test.ts`.
- **Web UI Layer (`apps/web`)**:
  - `InspectorPanel` component supporting collapsed and expanded states, tab navigation, active object indicator, and inputs across identity, ownership, technical, classification, risk, SLA, and documentation sections.
  - Tests in `apps/web/inspector-panel.spec.tsx` verifying collapsed state, field inputs, tab headers, and metadata change dispatch.
