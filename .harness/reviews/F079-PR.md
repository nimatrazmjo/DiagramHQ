# Pull Request: F079 — Azure

## Description
Microsoft Azure cloud infrastructure import and topology mapping engine for DiagramHQ (Phase 10 — Infrastructure Integrations). Provides complete feature parity with F078 (AWS), enabling engineering teams to import and map real Azure cloud architectures across subscriptions, resource groups, and regions directly into the DiagramHQ architecture model:
- Discovers and maps all 15 canonical Azure resource types:
  - Compute: `vm` (Virtual Machines), `app_service` (Web Apps), `function_app` (Serverless Functions), `aks` (Kubernetes clusters), `container_app` (Microservice apps)
  - Storage & Databases: `sql_database` (Azure SQL), `cosmos_db` (NoSQL DocumentDB), `storage_account` (Blob/Table/Queue storage)
  - Networking & Edge: `vnet` (Virtual Networks), `app_gateway` (Application Gateway), `front_door` (Global CDN/Ingress), `api_management` (APIM Gateway)
  - Messaging & Integration: `service_bus` (Queues/Topics), `event_hubs` (Streaming data), `event_grid` (Reactive pub/sub)
- Maps Azure resources into typed `ModelObject` records with:
  - `kind`: `'group'` for VNets, `'store'` for databases & storage accounts, `'application'` for compute, ingress, & gateways, `'component'` for messaging & event brokers
  - Standardized metadata: Azure Resource IDs, subscription ID, resource group, primary location, VNet IDs, subnet IDs, and user tags
  - Hierarchical containment: resources deployed into a VNet have `parentId` anchored to the VNet group object when VNet containment is enabled
- Inter-resource connection inference:
  - Detects and creates typed `ModelConnection` records between interdependent Azure services:
    - Front Door -> APIM / App Service / App Gateway (Global Ingress routing)
    - APIM -> Functions / App Service / AKS (Backend API calls)
    - App Gateway -> AKS / VM (Load balanced HTTP/HTTPS traffic)
    - App Service / AKS / VM -> SQL Database (T-SQL queries), Cosmos DB (REST operations), Storage Account (Blob operations)
    - App Service / Functions -> Service Bus / Event Hubs (Async event publishing)
    - Event Grid -> Functions / Service Bus (Reactive cloud event trigger)
- Traceable cloud evidence: generates `AzureCloudEvidence` records (`sourceType: 'cloud_resource'`) with 100% confidence referencing raw Azure Resource IDs, locations, resource groups, and subscription IDs.
- Acceptance test verified: imported a mocked Azure subscription with all 15 canonical Azure resource types correctly mapped to model objects, connections, and evidence.
