# Pull Request: F073 — GitLab

## Description
Implements GitLab project connectivity and static repository code analysis with full feature parity to the GitHub scanner (F072). Analyzes GitLab repositories across groups, subgroups, and project namespaces (`namespace/project`), scanning manifests (`package.json`, `pom.xml`, `requirements.txt`, `go.mod`), configuration files (`docker-compose.yml`, `.gitlab-ci.yml`), and route handlers to detect:
- Services & Applications
- Exposed APIs & Endpoints
- Persistent Datastores (PostgreSQL, MySQL, Redis, MongoDB)
- Message Queues (Kafka, RabbitMQ)
- Frameworks and libraries (NestJS, Express, Next.js, Fastify)
- Cloud SDKs (AWS SDK, Google Cloud Client, Azure SDK)
- GitLab CI services & test containers defined in `.gitlab-ci.yml`

Strict Acceptance Invariant:
- Same detection + mapping coverage for GitLab as GitHub.
- Every detected architectural entity carries concrete code evidence (project path, file path, line numbers) and calibrated confidence assessment (high/medium/low).
- All discovered objects and connections are delivered as reviewable proposals for human-in-the-loop inspection before model mutation.

### Key Additions
1. **Domain Layer (`packages/domain/src/gitlab-scanner.ts`)**:
   - `scanGitLabRepository(input)`: parses GitLab project trees and manifests, including `.gitlab-ci.yml` services, extracting services, datastores, queues, and APIs with grounded `AIEvidence` and calibrated confidence.
   - `packages/domain/src/gitlab-scanner.test.ts`: 3 unit tests verifying parity with GitHub scanner on equivalent repositories, `.gitlab-ci.yml` service discovery, and heuristic fallback for minimal repositories.
   - `packages/domain/src/index.ts`: Exported `gitlab-scanner`.

2. **Web Layer (`apps/web/components/canvas/gitlab-scanner-panel.tsx`)**:
   - `<GitLabConnectModal />`: GitLab project connection modal with support for project namespaces and ref/branch selection.
   - `<GitLabScanResultDrawer />`: Reviewable proposal drawer displaying discovered entities with GitLab project badge (🦊), confidence badges, code citations, and model import action.
   - `apps/web/components/canvas/index.ts`: Exported GitLab scanner components.
   - `apps/web/gitlab-scanner.spec.tsx`: 4 integration tests verifying scanner parity, modal and drawer rendering, and empty states.
