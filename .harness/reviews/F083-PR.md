# Pull Request: F083 — Cloud resource discovery

## Description
Live multi-cloud resource discovery and architecture proposal engine for DiagramHQ (Phase 10 — Infrastructure Integrations):
- Multi-cloud live resource discovery across accounts and subscriptions:
  - Discovers live resources across AWS, Azure, GCP, and Kubernetes accounts.
  - Classifies resources into functional categories: compute, database, storage, networking, messaging, and security.
  - Determines canonical C4 ModelObjectKind (`application`, `store`, `group`, `component`).
  - Supports network boundary and multi-tenant scoping (e.g. AWS VPCs, Azure VNets, K8s namespaces).
- Intelligent architecture reconciliation and proposal generation:
  - Compares discovered resources against the active architecture model:
    - **Creates (`create`)**: Proposes new `ModelObject` instances for unmapped live cloud assets.
    - **Updates (`update`)**: Detects attribute changes (status, region, tags) on matched existing objects.
    - **Drift / Stale (`remove_stale`)**: Flags previously mapped model objects whose backing cloud resources have been terminated or removed.
    - **Up-to-date (`matched`)**: Accurately matches identical objects without generating redundant diffs.
- Grounded cloud evidence:
  - Every proposal attaches traceable `CloudDiscoveryEvidence` with resource ID/ARN, provider, account name & ID, region, confidence rating (>= 0.9), discovery timestamp, and calibrated match explanation.
- Human-in-the-loop review & execution:
  - `applyDiscoveryProposals` executes accepted proposals into typed `ModelObject` records (`createObjectIdForKind`).
- Canvas UI Integration:
  - `<CloudDiscoveryModal />`: Interactive modal featuring connected cloud accounts multi-select, live scan trigger, summary KPI metrics, provider and category filter chips, proposal card list with action badges (CREATE, UPDATE, REMOVE STALE), expandable evidence drawers, and bulk proposal application.
