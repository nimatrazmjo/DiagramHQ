# PR: F001 — Scaffold pnpm monorepo (web, api, domain, config) + Docker

Branch: `feat/F001-project-architecture` -> `main`

## Summary
Establishes the buildable foundation for DiagramHQ: a pnpm/TypeScript monorepo
with a Next.js web app, a NestJS api (health endpoint), a framework-free domain
package, shared config, Docker, and CI.

## Changes
- Workspace: apps/web, apps/api, packages/domain, packages/config; strict TS base.
- Tooling: ESLint (type-import rule scoped off for NestJS DI), Prettier, Vitest,
  scripts/init.sh, filled-in CLAUDE.md commands.
- Docker: multi-stage Dockerfiles (api via `pnpm deploy`, web via Next standalone),
  docker-compose (web/api/postgres/redis), GitHub Actions CI.

## Testing
`pnpm typecheck`, `pnpm lint`, `pnpm test` (4), `pnpm build` — all green locally.
Docker images not built in the sandbox (no Docker) — run `docker compose build`.
