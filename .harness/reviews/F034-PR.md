# F034 — Component diagrams

## Summary
Implements Component diagrams (Level 3 C4 view) as saved views over the model.

- **Domain layer (`packages/domain/src/view.ts`)**:
  - Added `createComponentViewOptions(name, filter)` returning `kind: 'component'`.
  - Added `isComponentView(view)` type discriminator.
  - Returns `Level 3 — Component` in `getViewLevelLabel`.
  - Unit tested in `packages/domain/src/view.test.ts`.
- **API integration (`apps/api/src/views/component-diagram.e2e.spec.ts`)**:
  - Creates Component diagram (Level 3) with container filter and coordinates.
  - Renders components from model with layout positions (`GET /views/:id/objects`).
  - Supports layout position updates via `PATCH /views/:id/objects/:objectId/position`.
  - Verifies view deletion keeps all underlying model entities (system, application, components) intact.
- **Web client (`apps/web/component-diagram.spec.ts`)**:
  - Tests domain view helpers and Level 3 label resolution for component diagrams.
