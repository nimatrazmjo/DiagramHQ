## Description
Implements **F023 — System** from Phase 03 (Architecture Model): System element CRUD, rendering, internal vs external system classification, domain & criticality metadata, container drill-down controls, and canvas projection.

- **Domain Layer (`packages/domain`)**:
  - `SystemMetadata` interface: `external`, `systemType`, `domain`, `critical`, `c4Level`, `c4Kind`.
  - `SystemNodeData` interface: `label`, `external`, `systemType`, `domain`, `critical`, `description`, `canDrillDown`, `systemId`.
  - Helpers: `createSystem` (`kind: 'system'`, `sys_` ID prefix), `isSystem`, `isExternalSystem`, `isInternalSystem`.
  - Canvas projection: `projectSystemToCanvas` mapping internal and external systems to React Flow canvas nodes with appropriate dimensions, styling data, and drill-down capability.
  - Integration with `c4-context.ts` re-exporting `isExternalSystem` and `isInternalSystem` to eliminate duplication.
  - 5 unit tests in `packages/domain/src/system.test.ts`.
- **API Layer (`apps/api`)**:
  - 6 comprehensive E2E tests in `apps/api/src/architectures/system.e2e.spec.ts` covering:
    - Internal System creation with domain, systemType, and criticality.
    - External System creation (third-party SaaS integration).
    - System-to-System connection (sync/async communication).
    - Updating System properties via `PATCH /objects/:id`.
    - Architecture model snapshot reload identity (`isModelIdentical`).
    - Deletion of System with cascading connection removal.
- **Web Client Layer (`apps/web`)**:
  - `SystemNode` component (`apps/web/components/canvas/system-node.tsx`) rendering:
    - Internal vs external system styling (solid blue border vs dashed slate border).
    - System icon / Cloud SaaS icon.
    - Domain tag (`[Domain: ...]`) and System Type badge (`[Type: ...]`).
    - Criticality tag (`[Tier 0]`).
    - Interactive container drill-down button with custom event dispatch and callback invocation.
    - 4-way connection handles on all 4 directions.
  - Registration in `apps/web/components/canvas/custom-nodes.tsx` for `system` and `default`.
  - 6 tests in `apps/web/system.spec.ts` covering internal system SSR rendering, external system styling, drill-down callback invocation, canvas mounting with `InfiniteCanvas`, and `ArchitectureModelClient` reload identity.
