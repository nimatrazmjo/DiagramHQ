# F092 — Architecture Documentation — Pull Request

## Summary
Implements the model-first Architecture Documentation engine and navigation tree for DiagramHQ (Phase 12 — Documentation). Transforms every architecture model entity into a rich, living documentation page and hierarchical navigation tree with grounded metadata, inbound caller interfaces, outbound dependencies, subcomponent hierarchies, and Markdown synthesis.

## Changes

### Domain (`packages/domain/src/`)
- **`architecture-documentation.ts`**: Pure architecture documentation domain engine:
  - **`buildArchitectureDocTree(model, options)`**: Builds a hierarchical navigation tree of all architecture objects rooted at the system overview, preserving parent-child containment (`parentId`), tree depths, paths (`/docs/system/container/component`), and inbound/outbound connection counts with cycle prevention.
  - **`generateObjectDocPage(objectId, model, context)`**: Compiles comprehensive living documentation for any object from its metadata and topology graph:
    - Identity, kind, description, breadcrumb trail, and parent container link.
    - Normalized governance and ownership (team, owner, repository URL, external docs).
    - Technical specifications (technology stack, environment, domain, criticality, data classification, tags, compliance).
    - Inbound callers table with protocols, technologies, and actions.
    - Outbound dependencies table with target kind, protocols, technologies, and actions.
    - Contained child subcomponents table with status and technology.
    - Operational resilience details (SLA, RTO, RPO).
    - Associated artifacts: ADRs, Execution Flows, and Views.
    - Structured sections and synthesized GitHub Flavored Markdown document.
  - **`generateArchitectureOverviewDocPage(model, context)`**: Synthesizes architecture-wide overview doc page with entity breakdown, tech stack summary, and top-level subsystems.
  - **`generateArchitectureDocPages(model, context)`**: Compiles doc pages for all objects in the model.
  - **`exportArchitectureDocsAsCatalog(model, context)`**: Bundles the tree, overview, and all object doc pages into a unified catalog structure.
  - **`renderDocPageToMarkdown(page)`**: Serializes structured doc page into standardized GitHub Flavored Markdown.
  - **`findDocTreeNode`**, **`flattenDocTree`**, **`getDocBreadcrumbs`**, **`searchDocTree`**: Navigation and query utilities.
- **`architecture-documentation.test.ts`**: 11 unit tests covering tree construction, depth/path calculation, breadcrumb resolution, search, metadata extraction, inbound/outbound connections, ADR integration, catalog export, and error handling.
- **`index.ts`**: Exported `architecture-documentation`.

### Web (`apps/web/`)
- **`components/canvas/architecture-documentation-panel.tsx`**: `<ArchitectureDocumentationModal />` canvas UI:
  - Header banner with object count and architecture title.
  - Breadcrumb navigation trail bar with quick jump buttons.
  - Left navigation tree sidebar with real-time search filter, kind badges, connection counts, and active selection highlighting.
  - Right doc viewer with 5 tabs:
    - Overview & Metadata (spec cards, structured sections, tags, governance).
    - Connections & Interfaces (Inbound Callers table + Outbound Dependencies table).
    - Hierarchy & Subcomponents (grid of child components with quick-open buttons).
    - Markdown Spec (syntax pre-block with Copy Markdown button).
    - Associated Artifacts (ADRs with status badges, Flows, Views).
  - Target in Canvas button to locate and focus node.
- **`components/canvas/index.ts`**: Exported `architecture-documentation-panel`.
- **`architecture-documentation.spec.tsx`**: 3 integration tests covering closed modal, full tree render, object documentation render from metadata + connections, and breadcrumb navigation.
