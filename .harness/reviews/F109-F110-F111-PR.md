# F109, F110, F111 — Command palette, Global search & Keyboard shortcuts

## Summary

Implemented complete ⌘K command palette, instant multi-field global search, and universal keyboard shortcuts for DiagramHQ (Phase 02 — Canvas):
- **F109 — Command palette**: Quick command execution for creating systems, apps, databases, queues, components, actors, and connections; C4 level navigation; JSON export; share links; and Ask AI Copilot (stub). Creation and connection actions dispatch through the client-model command layer (`defaultCommandDispatcher`) with full ⌘Z undoability.
- **F110 — Global search**: Rapid fuzzy search (< 20ms) across architecture objects indexing name, kind, technology, tags (`#tag`), and description. Results are grouped by category with visual headers, and selecting an object emits `canvas:center-node` to smoothly center the viewport.
- **F111 — Keyboard shortcuts**: Complete keymap support across DiagramHQ:
  - `⌘K` or `/`: Opens/closes Command Palette & Global Search
  - `Space`: Freeform panning across the infinite canvas
  - `F`: Fit view to graph content
  - `Delete` / `Backspace`: Deletes selected nodes and edges
  - `⌘Z` / `⌘⇧Z`: Undo and redo via universal command dispatcher
  - `⌘C` / `⌘V` / `⌘D`: Copy, paste, and duplicate selections
  - `1` / `2` / `3`: Switch C4 view levels (1 Context, 2 Containers, 3 Components)
  - `isTextInput` focus guard: Ensures shortcuts are ignored when typing inside input, textarea, select, or contentEditable elements.
