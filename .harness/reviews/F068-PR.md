# PR: F068 — AI documentation

## Feature Summary
Implemented pure AI Architecture Documentation generator and synchronizer for DiagramHQ (Phase 08 — AI Copilot). Automatically generates structured technical documentation grounded in architecture models, topology, metadata, and ADRs:
- Component-level documentation (`generateObjectDocumentation`): synthesizes component overview, runtime classification, incoming integration callers & interfaces, downstream egress dependencies, linked ADR decisions, and team ownership & governance contacts.
- System-level documentation (`generateSystemArchitectureDocumentation`): synthesizes platform overview, executive summary, complete component catalog table, and graph invariant topology summaries.
- Invariant: Zero hallucinations — 100% of cited entities are grounded references directly validated against the active architecture model.
- Model change synchronization (`refreshDocumentationOnModelChange`): automatically updates documentation when nodes or connections are added, modified, or removed.
- Reusable canvas UI components `<AIDocumentationCard />` and `<DocumentationViewerModal />` with interactive grounded reference pills and live auto-refresh.
