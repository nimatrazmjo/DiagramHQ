# F130 — Circular + SPOF Detection — Pull Request

## Summary
Implements Circular Dependency and Single Point of Failure (SPOF) structural risk detection engine for DiagramHQ (Phase 11 — Drift and Governance). This completes the final feature in Phase 11.

## Changes

### Domain (`packages/domain/src/`)
- **`circular-spof.ts`**: Pure structural risk detection engine:
  - **`detectCircularDependencies(model)`**: Detects all directed circular dependency loops via DFS with recursion stack. Classifies synchronicity (`sync` RPC vs `async`/`data`), assigns severity (`critical`, `high`, `medium`), provides full hop path visual descriptions (`A ➔ B ➔ C ➔ A`), and generates targeted breaking edge suggestions (`invert dependency` or `convert to event bus topic`).
  - **`findArticulationPoints(nodes, connections)`**: Tarjan's bridge cut-vertex algorithm ($O(V+E)$) detecting nodes that partition graph connectivity upon failure.
  - **`detectSinglePointsOfFailure(model, options)`**: Detects SPOF components across 5 risk categories:
    1. `fan_in_bottleneck`: High incoming in-degree convergence without active redundancy.
    2. `sole_provider`: Upstream dependent nodes routing 100% of outbound traffic through this single node.
    3. `articulation_point`: Cut-vertex components whose outage partitions topology clusters.
    4. `unreplicated_store`: Primary databases lacking multi-AZ replication or replica fallback.
    5. `unmitigated_hub`: High-traffic components lacking HA or clustered failover metadata.
    - Generates actionable mitigations (HA clustering, replicas, circuit breakers, asynchronous decoupling).
  - **`analyzeStructuralRisks(model, options)`**: Computes `StructuralRiskMetrics`, structural health score (0–100), overall risk level (`healthy`, `warning`, `critical`), and prioritized architectural recommendations.
- **`circular-spof.test.ts`**: 6 unit tests covering seeded cycles, seeded SPOF on fan-in, articulation cut vertices, unreplicated stores, redundant HA mitigation, and structural risk reporting.
- **`index.ts`**: Exported `circular-spof`.

### Web (`apps/web/`)
- **`components/canvas/circular-spof-panel.tsx`**: `<CircularSpofModal />` canvas UI component:
  - Structural score gauge and overall risk badge.
  - 6 KPI metric cards (Structural Score, Cycles Detected, SPOFs Flagged, Articulation Points, Max Fan-In, Critical Risks).
  - Prioritized architectural recommendations banner.
  - 3 view tabs: All Risks, Cycles (with hop sequence arrows and breaking edge advice), and SPOFs (with fan-in, dependent services, rationale, and mitigation advice).
  - Severity dropdown and real-time search filters.
  - Action buttons: Copy Summary and Export JSON.
- **`components/canvas/index.ts`**: Exported `circular-spof-panel`.
- **`circular-spof.spec.tsx`**: 2 integration tests covering modal rendering, cycle/SPOF display, and closed state.
