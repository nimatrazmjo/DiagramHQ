## Description
Implements **F032 — Context diagrams** from Phase 04 (Diagrams and Views): Context diagram type as a model-first saved view (Level 1), allowing objects to appear in multiple diagrams, and verifying that deleting an object from a diagram retains it in other diagrams and in the underlying architecture model.

- **Domain Layer (`packages/domain`)**:
  - `CreateViewOptions` interface with `name`, `kind: ViewKind`, and optional `filter`.
  - Helpers: `createContextViewOptions`, `isContextView`, `getViewLevelLabel`.
  - Unit tests in `packages/domain/src/view.test.ts`.
  - Exported in `packages/domain/src/index.ts`.
- **API Layer (`apps/api`)**:
  - View management endpoints in `ViewsController` and `ViewsService`:
    - `POST /architectures/:architectureId/views`: creates a new saved view.
    - `GET /architectures/:architectureId/views`: lists all saved views.
    - `GET /views/:id`: retrieves view metadata.
    - `DELETE /views/:id`: deletes a view without deleting underlying model objects.
    - `POST /views/:viewId/objects`: adds an object to a diagram with optional position override.
    - `DELETE /views/:viewId/objects/:objectId`: removes an object from a diagram.
    - `GET /views/:viewId/objects`: lists objects in a diagram.
  - Integration tests in `apps/api/src/views/context-diagram.e2e.spec.ts`:
    - Create Context diagram (kind: context).
    - RBAC: reject view creation by viewers (HTTP 403).
    - Object appearance in multiple diagrams concurrently.
    - Deleting an object from one diagram keeps it in another diagram and keeps it in the architecture model (`GET /architectures/:id/model`).
    - Listing architecture views.
- **Web Layer (`apps/web`)**:
  - Tests in `apps/web/context-diagram.spec.ts` verifying domain view helpers.
