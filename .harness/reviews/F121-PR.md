# Pull Request: F121 — Specialized agents

## Description
Implements the 7 specialized role-based architectural AI agents operating directly over DiagramHQ's Model Context Protocol (MCP) tool surface. Dispatches role-calibrated agent workflows to analyze, design, audit, and safely propose modifications across architecture models:
1. `Analyst Agent`: evaluates domain boundaries, cohesion, coupling indices, fan-in/fan-out, and architectural bottlenecks using `search_architecture`, `get_dependencies`, and `get_dependents`.
2. `Designer Agent`: synthesizes C4 container topologies, component boundaries, and interface contracts using `create_object`, `create_diagram`, and `create_flow`, yielding reviewable proposals.
3. `Security Agent`: executes zero-trust threat modeling, perimeter ingress validation, and blast radius calculations using `search_architecture` and `analyze_impact`.
4. `Cloud Agent`: audits infrastructure mapping, cloud provider managed services, persistent datastores, and multi-AZ high availability resilience.
5. `Documentation Agent`: compiles comprehensive C4 architecture catalog cards and Markdown technical specifications with grounded attributes.
6. `Migration Agent`: formulates phased cutover strategies (Strangler Fig pattern), dual-write replication plans, and decommissioning change proposals using `create_change` and `delete_object`.
7. `Code Agent`: verifies repository-to-model alignment, AST static analysis grounding, and detects architectural drift.

Strict Invariant Enforced:
- All mutating actions dispatched by any specialized agent produce explicit reviewable proposals (`MCPToolProposal` with `isProposal: true, requiresApproval: true`), guaranteeing no silent commits.

### Key Additions
1. **Domain Layer (`packages/domain/src/specialized-agents.ts`)**:
   - `SPECIALIZED_AGENT_REGISTRY`: registry of all 7 specialized agent metadata records, titles, capabilities, and preferred MCP tools.
   - `SpecializedAgentDispatcher`: orchestrates execution of scoped tasks over `DiagramHQMCPServer` via asynchronous tool dispatching and proposal collection.
   - `packages/domain/src/specialized-agents.test.ts`: 8 unit tests verifying that all 7 agents execute and complete scoped tasks on the MCP tool surface, with mutating operations producing reviewable proposals.
2. **Web Layer (`apps/web/components/canvas/specialized-agents-panel.tsx`)**:
   - `<SpecializedAgentSelector />`: role selector with icons, capability details, preferred MCP tool badges, and custom task instruction launcher.
   - `<SpecializedAgentResultCard />`: structured output viewer showing status, execution timestamp, invoked MCP tools, findings, and reviewable proposal cards with "Approve Proposal" action.
   - `<SpecializedAgentDrawer />`: modal overlay containing role selection, execution trigger, and activity stream.
   - `apps/web/specialized-agents.spec.tsx`: 5 integration tests verifying all 7 agents complete scoped tasks, proposal requirements for mutating operations, and UI component rendering.
